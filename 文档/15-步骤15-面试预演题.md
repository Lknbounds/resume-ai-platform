# 步骤 15：面试预演题生成（5 小时）

> **目标**：根据"已结构化的简历要点 + JD 技能要求"生成 6-10 道可能被问到的面试题，每题带**考察点**和**回答应覆盖的要点**；可选"参考公开信息"模式注入面经素材；AI 关闭时**整个模块消失**。
>
> 这是**独立模块**：失败不影响分析，不参与 ATS 评分。

## 15.2 为什么这样设计（面试可讲）

**① 为什么面试题要独立成模块，还整体隐藏？**
- 它与 ATS 评分**没有因果关系**（评的是"简历与岗位匹配"，不评"你会不会被问到什么"）；混进主链路会让"分数"这个核心指标变得浑浊；
- 它**没有合格的规则替代品**：没有 AI 就只能是"通用题库"，对用户毫无针对性。与其给一个假的功能，不如关掉；
- 失败可能来自 AI 超时/额度，不能让它拖累核心功能（这也是为什么它有自己的表和状态）。

**② 输入为什么是"已结构化的要点"而不是原始简历全文？**
- 题目要"贴着简历问"，所以需要 `projects / experiences / skills` 这些结构化字段，而不是让模型从 8000 字里自己找；
- 结构化输入**显著缩短 prompt**（省 token、降延迟）；
- 更重要：题目能引用"具体事实"（"你写的 QPS 200→1200"），而不是泛泛而谈。

**③ 为什么要"考察点 + 回答要点"？**
只有题目的话，用户看完还是不会答。加上"考察点"（面试官想看什么）和"关键要点"（回答应该覆盖什么），它才从"题库"变成"预演"。
这也是对"不编造"的呼应：**我们不替用户编答案，只告诉他该覆盖哪些点**。

**④ "参考公开信息"为什么要做成可关闭的注入，而不是直接让模型上网搜？**
三层理由：
- **可控**：外部信息只作为"话题提示"进入 prompt，题目仍必须结合**该用户的简历与 JD**；
- **可靠**：本地 JSON 数据集，零外部依赖、零失败可能（真实搜索 API 会超时、会限流、内容不可控）；
- **可关闭**：有些用户不希望自己的信息与外部素材混在一起，开关给出选择。

**⑤ 为什么外部素材不能直接决定题目？**
如果模型照着面经原样出题，就会出现"你简历里根本没写 Kafka，却问你 Kafka 幂等" —— 用户会觉得这个工具不懂他。
所以规则是：**素材只用来提示"这个话题值得问"，具体问法必须锚定简历里的真实内容**；`refNote` 字段只是标注"参考了哪个话题"，不复制原文。

**⑥ 为什么要落库并支持按版本查历史？**
- 用户在准备面试时会反复看，不能每次都重新生成（贵且慢、内容还会变）；
- 同一份简历在不同 JD 下生成的题不同，要能按"版本 + 岗位"归档；
- 失败批次也落库，便于排查"为什么这次生成失败"。

**⑦ 为什么用"批次 + 题目"两张表？**
一次生成是原子操作（要么 8 题都要，要么失败），批次表承载状态/耗时/模型/外部素材引用；题目表承载内容。
如果只有一张表，失败时要么留半成品（用户看到 3 题以为只有 3 题），要么全删（丢失失败原因）。**失败时批次为 FAILED、题目为空**，语义清晰。

## 15.4 外部信息提供者（可插拔）

```java
package com.jianli.interview.dataset;

import java.util.List;

public interface ExternalInfoProvider {

    String source();                      // DATASET / SEARCH / NONE

    boolean enabled();

    /** 按岗位与技能找相关素材；不保证有结果 */
    List<ExternalRef> find(String position, List<String> skills, int limit);
}
```

```java
public record ExternalRef(String id, String topic, List<String> points, String sourceNote) {}
```

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class DatasetExternalInfoProvider implements ExternalInfoProvider {

    private final ObjectMapper objectMapper;
    private final AppInterviewProperties props;   // app.interview.external-info.enabled

    private List<Entry> cache;

    @PostConstruct
    void load() {
        try (InputStream in = new ClassPathResource("interview/dataset.json").getInputStream()) {
            cache = objectMapper.readValue(in, new TypeReference<List<Entry>>() {});
            log.info("interview dataset loaded: {} entries", cache.size());
        } catch (Exception e) {
            log.error("interview dataset load failed", e);
            cache = List.of();
        }
    }

    @Override public String source() { return "DATASET"; }
    @Override public boolean enabled() { return props.enabled(); }

    @Override
    public List<ExternalRef> find(String position, List<String> skills, int limit) {
        if (!enabled() || cache.isEmpty()) return List.of();
        String pos = position == null ? "" : position.toLowerCase(Locale.ROOT);
        Set<String> skillSet = skills.stream()
                .map(s -> s.toLowerCase(Locale.ROOT)).collect(Collectors.toSet());

        return cache.stream()
                .map(e -> Map.entry(e, score(e, pos, skillSet)))
                .filter(x -> x.getValue() > 0)
                .sorted((a, b) -> Integer.compare(b.getValue(), a.getValue()))
                .limit(limit)
                .map(x -> new ExternalRef(x.getKey().id(), x.getKey().topic(),
                        x.getKey().points(), x.getKey().sourceNote()))
                .toList();
    }

    private int score(Entry e, String position, Set<String> skills) {
        int s = 0;
        for (String kw : e.positionKeywords()) if (position.contains(kw.toLowerCase(Locale.ROOT))) s += 2;
        for (String tag : e.techTags()) if (skills.contains(tag.toLowerCase(Locale.ROOT))) s += 3;
        return s;
    }

    record Entry(String id, List<String> positionKeywords, List<String> techTags,
                 String topic, List<String> points, String sourceNote) {}
}
```

> **这个接口的价值**：以后想接真实搜索 API，只需新增一个 `SearchExternalInfoProvider` 实现 + 配置切换，**业务代码完全不动**。这就是"可插拔"的具体好处，面试时可以直接这么讲。

## 15.7 服务

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class InterviewService {

    private final InterviewQuestionSetRepository setRepository;
    private final InterviewQuestionRepository questionRepository;
    private final ResumeService resumeService;
    private final JobDescriptionRepository jdRepository;
    private final AiGateway aiGateway;
    private final AiFeatureGate gate;
    private final ExternalInfoProvider externalInfoProvider;
    private final ObjectMapper objectMapper;

    /** 创建批次 + 异步生成 */
    @Transactional
    public Long create(Long userId, CreateInterviewRequest req) {
        if (!gate.isAiAvailable(AiFeature.INTERVIEW)) {
            throw new BizException(ErrorCode.INTERVIEW_DISABLED);
        }
        var version = resumeService.requireOwnedVersion(userId, req.resumeVersionId());
        var jd = jdRepository.findByIdAndUserId(req.jdId(), userId)
                .orElseThrow(() -> new BizException(ErrorCode.JD_NOT_FOUND));

        InterviewQuestionSet set = new InterviewQuestionSet();
        set.setUserId(userId);
        set.setResumeVersionId(version.getId());
        set.setJdId(jd.getId());
        set.setStatus("PENDING");
        set.setUseExternalInfo(Boolean.TRUE.equals(req.useExternalInfo()));
        set.setExternalSource(set.getUseExternalInfo() ? externalInfoProvider.source() : "NONE");
        set = setRepository.save(set);

        Long setId = set.getId();
        // 独立线程池，与分析任务隔离（互不影响）
        CompletableFuture.runAsync(() -> generate(setId, req.count() == null ? 8 : req.count()));

        return setId;
    }

    void generate(Long setId, int count) {
        long start = System.currentTimeMillis();
        var set = setRepository.findById(setId).orElseThrow();
        try {
            set.setStatus("RUNNING");
            setRepository.save(set);

            var version = resumeVersionRepository.findById(set.getResumeVersionId()).orElseThrow();
            var jd = jdRepository.findById(set.getJdId()).orElseThrow();

            // 复用分析阶段的解析结果（不重复调 AI）
            var jdParsed = readJd(jd);
            var resumeParsed = readResume(set);

            List<ExternalRef> refs = List.of();
            if (Boolean.TRUE.equals(set.getUseExternalInfo()) && externalInfoProvider.enabled()) {
                refs = externalInfoProvider.find(jd.getTitle(),
                        jdParsed == null ? List.of() :
                                jdParsed.requiredSkills().stream().map(s -> s.name()).toList(), 3);
                set.setExternalRefs(objectMapper.writeValueAsString(
                        refs.stream().map(ExternalRef::id).toList()));
            }

            var result = aiGateway.interview(
                    jd.getTitle(), skillsOf(jdParsed), projectsOf(resumeParsed),
                    experiencesOf(resumeParsed), topicsOf(refs), count);

            int i = 0;
            for (InterviewQ q : result.data()) {
                InterviewQuestion eq = new InterviewQuestion();
                eq.setSetId(setId);
                eq.setSortNo(i++);
                eq.setCategory(normalizeCategory(q.category()));
                eq.setQuestion(q.question());
                eq.setIntent(q.intent());
                eq.setKeyPoints(objectMapper.writeValueAsString(q.keyPoints()));
                eq.setFollowUp(q.followUp());
                eq.setSource("AI");
                eq.setRefNote(q.refNote());
                questionRepository.save(eq);
            }

            set.setStatus("SUCCESS");
            set.setModel("qwen-plus");
            set.setQuestionCount(i);
            set.setDurationMs((int) (System.currentTimeMillis() - start));
            setRepository.save(set);

        } catch (Exception e) {
            log.error("interview generation failed, setId={}", setId, e);
            set.setStatus("FAILED");
            set.setErrorMessage(truncate(e.getMessage(), 500));
            setRepository.save(set);
            // 不抛异常：失败只影响本模块
        }
    }
}
```

`AiGateway` 增加一个方法：

```java
ParseResult<List<InterviewQ>> interview(String position, List<String> skills,
                                        List<String> projects, List<String> experiences,
                                        List<String> topics, int count);
```

实现与其它方法同构（prompt + `entity()` + 校验 + 超时 45s + 失败返回空列表）。**校验规则**：`questions.size() <= 12`、`question` 非空且 ≤ 200 字、`category` 合法。

## 15.8 开关与前端隐藏（三重保障）

```json
// GET /api/meta/features
{ "aiEnabled": false, "interviewModuleEnabled": false, ... }
```

1. **导航栏**：`v-if="feature.interviewModuleEnabled"`；
2. **路由守卫**：`meta.feature === 'interview'` 且未开启 → 重定向并提示；
3. **接口**：`create` 里 `gate.isAiAvailable(INTERVIEW)` 为假 → `44001`。

三层都要，因为：前端可以改、URL 可以直接输、接口可以直接调。**真正的边界在服务端。**

const form = reactive({ resumeVersionId: null, jdId: null, useExternalInfo: false, count: 8 })
const generating = ref(false)

async function generate() {
  if (!form.resumeVersionId || !form.jdId) return ElMessage.warning('请选择简历版本与岗位')

  const { setId } = await interviewApi.create(form)

    }
  }, 2000)
}

## 15.12 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 一直 PENDING | 任务没提交成功 | 检查 `CompletableFuture.runAsync` 是否被吞异常 |
| 一直 RUNNING | 生成过程中抛异常 | `generate` 里必须 try/catch 并置 FAILED |
| 题目里出现了简历没有的技术 | 提示词约束不足 | 强化"必须锚定候选人简历"的要求；或后置校验过滤 |
| keyPoints 存成字符串不可读 | JSON 序列化后前端直接显示 | 前端 `JSON.parse` |
| 数据集没加载 | 路径写错 | 看日志 `interview dataset loaded: N entries` |
| 关掉 AI 后路由仍可访问 | 守卫没加 `meta.feature` | 三重保障缺一层 |
| 前端一直转圈 | 轮询没有上限 | 加 60 次上限 + 失败提示 |

## 15.13 自测题

1. **为什么面试题要独立模块 + 整体隐藏？** → 与评分无因果关系；没有 AI 就没有合格的替代品，宁缺毋滥。
2. **为什么输入是结构化要点？** → 题目能锚定具体事实、prompt 更短、成本更低。
3. **为什么外部素材只作提示不作定题？** → 否则会问候选人简历里根本没有的技术，显得不懂用户。
4. **为什么用"批次 + 题目"两张表？** → 失败语义清晰（批次 FAILED、无题目），而不是留半成品。
5. **可插拔 Provider 的价值？** → 换真实搜索 API 时业务代码零改动，只新增实现 + 配置。
6. **AI 关闭时为什么不是"返回空列表"而是 `44001`？** → 空列表会让用户以为"没有题"，语义错误；明确告知功能未开启，前端才能隐藏入口。
