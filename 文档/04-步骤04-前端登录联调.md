# 步骤 04：前端登录联调（6 小时）

> **目标**：浏览器打开 `localhost:5173`，能注册、登录、刷新页面不掉线、退出登录；改密码后所有设备被踢下线。
>
> 从这一步开始，**每完成一个后端接口就顺手做前端页面**，不要攒到最后一起做 —— 攒着做必然出现"接口对不上，到处改"。

---

## 4.1 这一步做出什么

| 页面/行为 | 说明 |
|---|---|
| `/login` | 用户名 + 密码登录，成功后跳回原来要去的页面 |
| `/register` | 注册后自动登录 |
| `/` 首页 | 顶部导航（首页 / 我的简历 / 岗位 JD / 社区 / 头像菜单） |
| `/me/profile` | 查看、修改昵称/目标岗位/经验年限；改密码 |
| 刷新页面 | 仍是登录态（token 存在 localStorage） |
| token 过期 | 自动静默刷新并重放请求，用户无感 |
| 退出 | 回到登录页，localStorage 清空，后端黑名单生效 |
| 接口报错 | 统一 `ElMessage.error`，不用每个页面写提示 |

---

## 4.2 为什么这样设计（面试可讲）

**① token 存哪里？为什么是 localStorage？**
三种选择：
- **内存（Pinia）**：最安全，但刷新页面就没了，用户要重新登录；
- **httpOnly Cookie**：JS 读不到，防 XSS 窃取，但需要后端配合 Set-Cookie + 前端 `withCredentials`，并且要重新引入 CSRF 防护；
- **localStorage**：刷新不掉线，前端完全掌控，但能被 XSS 读取。

本项目选 localStorage + Bearer 头，因为它和"前后端完全分离、后端无状态"的架构最自洽。**对应的风险控制就是：前端绝不用 `v-html` 渲染用户内容**（简历、评论全是纯文本）。这是一组配套的取舍，面试时要说清楚"我知道风险，也知道怎么控制"。

**② 为什么要有"刷新队列"？**
token 过期瞬间，页面上可能同时发 3 个请求（列表 + 详情 + 未读数），三个都会 401。如果每个 401 都去调 refresh：
- 第一个把旧 refresh 用掉并轮换；
- 后两个拿着作废的 refresh 去调 → 失败 → 用户被踢下线。

所以要做一个**单例 Promise**：第一个 401 触发刷新，其余请求等这个 Promise 完成后再各自重放。这段代码在 `http.js` 里，是全前端最值得讲的 20 行。

**③ 为什么 refresh 接口要用裸 `axios` 而不是 `http` 实例？**
`http` 实例挂了 401 拦截器。如果 refresh 请求本身 401（refresh 也过期了），拦截器又去调 refresh → 无限递归。
用裸 `axios` 绕开拦截器，刷新失败就直接清空登录态跳登录页。

**④ 为什么用 `window.location` 而不是 `router.push`？**
`http.js` 需要跳登录页，但它 `import router` 会造成**循环依赖**：`router → views → api/http → router`。Vite 下这种循环可能导致 `router` 在模块初始化时是 `undefined`，报 `Cannot read properties of undefined`。
跳转用 `window.location.href = '/login'` 简单粗暴且一定有效（顺便把内存里的脏状态全清掉）。

**⑤ 为什么要把"功能开关"也做成一个 store？**
`AI_ENABLED=false` 时，面试预演题入口必须整个消失。如果每个组件各自调 `/api/meta/features`，会重复请求且状态不一致。
放进 `useFeatureStore` 后：路由守卫、导航栏、报告页的降级提示都读同一份状态，且只请求一次。

**⑥ 为什么错误提示放拦截器，唯独 43002 不放？**
绝大多数错误（401、403、500、参数错误）用一句 `ElMessage.error` 就够了。但"个人信息审核不通过（43002）"需要弹一个**带高亮定位的对话框**，这个 UI 只有发布页知道怎么做。
所以约定：拦截器遇到 43002 只 `reject`，不弹提示，交给页面处理。

```java
public UserVO updateProfile(Long userId, UpdateProfileRequest req) {
    AppUser user = userRepository.findById(userId)
            .orElseThrow(() -> new BizException(ErrorCode.USER_NOT_FOUND));
    user.setNickname(req.nickname());
    user.setTargetPosition(req.targetPosition());
    if (req.yearsOfExperience() != null) user.setYearsOfExperience(req.yearsOfExperience());
    return UserVO.of(user);
}

@Transactional
public void changePassword(Long userId, ChangePasswordRequest req) {
    AppUser user = userRepository.findById(userId)
            .orElseThrow(() -> new BizException(ErrorCode.USER_NOT_FOUND));
    if (!passwordEncoder.matches(req.oldPassword(), user.getPasswordHash())) {
        throw new BizException(ErrorCode.BAD_CREDENTIALS);
    }
    user.setPasswordHash(passwordEncoder.encode(req.newPassword()));
    // 改密后所有设备强制重新登录
    tokenService.revokeAllRefresh(userId);
}
```

### 4.4.3 `src/api/http.js`（**全前端最重要的文件**）

```js
import axios from 'axios'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/stores/user'

const http = axios.create({
  baseURL: import.meta.env.VITE_API_BASE,
  timeout: 60000
})

// ---------- 请求：带 token ----------
http.interceptors.request.use((config) => {
  const user = useUserStore()
  if (user.accessToken) {
    config.headers.Authorization = `Bearer ${user.accessToken}`
  }
  return config
})

// ---------- 响应：解包 + 统一错误 ----------
http.interceptors.response.use(
  (res) => {
    const body = res.data
    if (body.code === 0) return body.data          // 成功：直接拿 data
    if (body.code === 43002) return Promise.reject(body)   // 审核不通过：交给页面处理
    ElMessage.error(body.message || '请求失败')
    return Promise.reject(body)
  },
  async (err) => {
    const { response, config } = err
    if (response?.status === 401 && !config._retry) {
      config._retry = true
      try {
        const token = await refreshOnce()
        config.headers.Authorization = `Bearer ${token}`
        return http(config)                        // 重放原请求
      } catch {
        useUserStore().clear()
        window.location.href = '/login'
        return Promise.reject(err)
      }
    }
    ElMessage.error(response?.data?.message || '网络异常，请稍后重试')
    return Promise.reject(err)
  }
)

// ---------- 刷新单例：并发 401 只刷新一次 ----------
let refreshingPromise = null

function refreshOnce() {
  if (!refreshingPromise) {
    const user = useUserStore()
    refreshingPromise = axios
      .post(`${import.meta.env.VITE_API_BASE}/auth/refresh`, {
        refreshToken: user.refreshToken
      })
      .then((res) => {
        if (res.data.code !== 0) throw new Error(res.data.message)
        user.setTokens(res.data.data)
        return user.accessToken
      })
      .finally(() => { refreshingPromise = null })
  }
  return refreshingPromise
}

export default http
```

> **注意**：`refreshOnce` 里用的是裸 `axios`（不是 `http`），否则会递归。

### 4.4.5 `src/stores/user.js`

```js
import { defineStore } from 'pinia'
import { authApi } from '@/api/auth'
import { userApi } from '@/api/user'

export const useUserStore = defineStore('user', {
  state: () => ({
    accessToken: localStorage.getItem('accessToken') || '',
    refreshToken: localStorage.getItem('refreshToken') || '',
    profile: null
  }),

  getters: {
    isLoggedIn: (s) => !!s.accessToken,
    displayName: (s) => s.profile?.nickname || s.profile?.username || '未登录'
  },

  actions: {
    setTokens({ accessToken, refreshToken }) {
      this.accessToken = accessToken
      this.refreshToken = refreshToken
      localStorage.setItem('accessToken', accessToken)
      localStorage.setItem('refreshToken', refreshToken)
    },

    async login(form) {
      const data = await authApi.login(form)
      this.setTokens(data)
      this.profile = data.user
      return data
    },

    async register(form) {
      await authApi.register(form)
      return this.login({ username: form.username, password: form.password })
    },

    async fetchProfile() {
      this.profile = await userApi.me()
      return this.profile
    },

    async logout() {
      try {
        await authApi.logout({ refreshToken: this.refreshToken })
      } catch {
        // 即使后端失败也清本地
      } finally {
        this.clear()
        window.location.href = '/login'
      }
    },

    clear() {
      this.accessToken = ''
      this.refreshToken = ''
      this.profile = null
      localStorage.removeItem('accessToken')
      localStorage.removeItem('refreshToken')
    }
  }
})
```

### 4.4.6 `src/stores/feature.js`

```js
import { defineStore } from 'pinia'
import { metaApi } from '@/api/meta'

export const useFeatureStore = defineStore('feature', {
  state: () => ({
    loaded: false,
    aiEnabled: false,
    aiFeatures: {},
    interviewModuleEnabled: false,
    externalInfoEnabled: true,
    scoringVersion: 'v1'
  }),

  actions: {
    async load() {
      if (this.loaded) return
      const data = await metaApi.features()
      this.aiEnabled = data.aiEnabled
      this.aiFeatures = data.aiFeatures || {}
      this.interviewModuleEnabled = data.interviewModuleEnabled
      this.externalInfoEnabled = data.externalInfoEnabled
      this.scoringVersion = data.scoringVersion
      this.loaded = true
    }
  }
})
```

```js
import { createRouter, createWebHistory } from 'vue-router'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/stores/user'
import { useFeatureStore } from '@/stores/feature'

const routes = [
  { path: '/login', component: () => import('@/views/auth/LoginView.vue'), meta: { layout: 'blank', title: '登录' } },
  { path: '/register', component: () => import('@/views/auth/RegisterView.vue'), meta: { layout: 'blank', title: '注册' } },
  { path: '/', component: () => import('@/views/dashboard/DashboardView.vue'), meta: { requiresAuth: true, title: '首页' } },
  { path: '/me/profile', component: () => import('@/views/me/ProfileView.vue'), meta: { requiresAuth: true, title: '个人资料' } },
  // 后续步骤在这里继续加：/resumes、/jds、/analysis、/community、/interview
  { path: '/:pathMatch(.*)*', redirect: '/' }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

router.beforeEach(async (to) => {
  const user = useUserStore()
  const feature = useFeatureStore()

  // 功能开关只拉一次
  if (!feature.loaded) {
    try { await feature.load() } catch { /* 后端没起也不该卡死路由 */ }
  }

  if (to.meta.requiresAuth && !user.isLoggedIn) {
    return { path: '/login', query: { redirect: to.fullPath } }
  }

  // AI 关闭时面试模块整体不可见（步骤 15 会用到）
  if (to.meta.feature === 'interview' && !feature.interviewModuleEnabled) {
    ElMessage.warning('面试预演功能未开启')
    return { path: '/' }
  }

  if (user.isLoggedIn && !user.profile) {
    try { await user.fetchProfile() } catch { /* 401 由拦截器处理 */ }
  }

  document.title = `${to.meta.title || '首页'} - AI 简历互评`
  return true
})

export default router
```

### 4.4.9 登录页 `src/views/auth/LoginView.vue`

```vue
<script setup>
import { reactive, ref } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/stores/user'

const router = useRouter()
const route = useRoute()
const user = useUserStore()

const formRef = ref()
const loading = ref(false)
const form = reactive({ username: '', password: '' })

const rules = {
  username: [{ required: true, message: '请输入用户名', trigger: 'blur' }],
  password: [{ required: true, message: '请输入密码', trigger: 'blur' }]
}

async function submit() {
  await formRef.value.validate()
  loading.value = true
  try {
    await user.login(form)

    router.replace(route.query.redirect || '/')
  } finally {
    loading.value = false
  }
}
</script>

          <el-input v-model="form.username" placeholder="4-32 位字母数字下划线" />
```

## 4.6 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面白屏，Console 报 `Cannot read properties of undefined (reading 'push')` | `http.js` 里 import 了 router（循环依赖） | 改用 `window.location.href` |
| 所有请求 401 且疯狂刷新 | refresh 走了 `http` 实例导致递归 | refresh 用裸 `axios` |
| 登录成功但跳不走 | `router.replace` 后被守卫拦回 | 检查 `redirect` 参数与取值逻辑 |
| 浏览器报 CORS | `SecurityConfig` 的 `corsSource` 没生效或前端没走代理 | 确认 `vite.config.js` 的 proxy 配置存在 |
| 刷新后变回未登录 | token 没写进 localStorage | 检查 `setTokens` 是否被调用 |
| `ElMessage` 未定义 | 没 `import { ElMessage } from 'element-plus'` | 补 import（Element Plus 的 JS API 不会自动注册） |
| 图标显示成空白 | 图标组件名写错 | 确认 `main.js` 里全量注册了图标 |
| 前端 5173 打不开 | 依赖没装 / 端口被占 | `npm install`；改 `vite.config.js` 端口 |

## 4.7 自测题

1. **三个并发请求同时 401，为什么只能刷新一次？** → 否则第一个刷新会轮换掉 refresh，后两个用失效的 refresh 失败，用户被误踢。
2. **refresh 接口为什么要绕开拦截器？** → 避免 401 递归。
3. **token 放 localStorage 的风险是什么，怎么控制？** → XSS 可读取；控制方式是绝不 `v-html` 渲染用户内容 + 后端输入校验。
4. **为什么功能开关要单独一个 store？** → 多个组件/守卫共享同一份状态，只请求一次，避免状态不一致。
5. **为什么 43002 不在拦截器里弹提示？** → 它需要页面级的"高亮定位"UI，拦截器不知道上下文。
