# 步骤 07：JD 管理与规则解析（6 小时）

> **目标**：粘贴一段真实 JD，后端**不用 AI、不花一分钱**抽出：硬技能清单（带重要度）、加分项、最低经验年限、学历要求、职责摘要。
>
> **这一步是整个 AI 设计的"地基"**：规则解析器先做出来，AI 才有"降级目标"；而且 AI 的输出结构（record）就是按规则解析器定义的。

---

## 7.2 为什么这样设计（面试可讲）

**① 为什么先写规则解析，而不是先接 AI？**
这是整个项目最重要的排期决策：
- **规则解析是 AI 的降级目标**。如果先做 AI，等 AI 挂了才发现"没有兜底"，需求就得重写；
- **规则解析定义了输出契约**。`JdParsed` 这个 record 的结构（有哪些字段、importance 取值）是由"规则能抽出来的东西"反推的，AI 只是用更好的方式填同一张表；
- **规则解析能离线跑单测**。100 份 JD 跑一遍，立刻知道准确率，而不是等 AI 配额。

**② 为什么用"技能词典"而不是正则硬编码技能？**
正则写 `(?i)(java|spring|mysql|redis...)` 会越来越长、难维护、加一个技能要改代码。
用 `skills.json`：结构是 `{canonical, aliases}`，一份数据同时服务**四处**（JD 解析、简历解析、关键词匹配、词面相似度降级）。加技能只改 JSON，不改代码。
这也是"AI 关闭时系统仍然有意义的底座"——没有词典，规则解析就只是个空壳。

**③ 重要度（HIGH/MEDIUM/LOW）怎么判的？**
在技能出现的**同一行**里找修饰词：

| 上下文词 | 判定 |
|---|---|
| 必须 / 精通 / 熟练掌握 / 熟练使用 / 扎实 | HIGH |
| 熟悉 / 掌握 / 具备…经验 | MEDIUM |
| 优先 / 加分 / 了解 / 者优先 | LOW |

同一行有多个修饰词时取最高。找不到修饰词 → MEDIUM（默认值）。
这不是完美的 NLP，但**可解释、可复现、可调**：用户问"为什么 Redis 是 MEDIUM"，你能指出"因为那一行写的是'熟悉 Redis'"。

**④ 为什么"加分项"单独一个字段，不放在 requiredSkills 里标 LOW？**
因为它们在评分里的作用完全不同：
- `requiredSkills` 参与**技能覆盖度**计算（权重 0.35）；
- `niceToHaveSkills` 只影响**加分项**（最多 +5 分）。
混在一起会导致"JD 写了 20 个'优先'技能，把覆盖率分母撑大，分数反而变低" —— 这是很隐蔽的评分 bug。

**⑤ 为什么解析结果要落库（`parsed_json`）而不是每次实时算？**
- 一次分析要反复用（评分、建议、面试题），每次都重算浪费；
- 解析结果要**可追溯**：报告里要存"当时这份 JD 被解析成什么"，模型或词典升级后历史仍可回看；
- 加上 `content_hash` 后可以跨用户复用（同一段 JD 文本解析结果相同）。

**⑥ 为什么 JD 的 `content_hash` 要拼上 `parserVersion`？**
只 hash 内容的话，词典升级后（比如新增了 50 个技能）旧缓存还在，用户拿到的还是旧的解析结果。
把 `parserVersion`（如 `rule-v1`）拼进 hash，**升级字典就必须升版本**，缓存自然失效。

**⑦ 为什么解析状态要分 `NONE/PARSING/SUCCESS/FAILED`？**
解析可能由 AI 触发（慢、可能失败），所以是异步可观测的状态机，而不是一个布尔值。前端能区分"没解析过"和"解析失败"。

```java
package com.jianli.ai.model;

import com.fasterxml.jackson.annotation.JsonIgnoreProperties;

import java.util.List;

/**
 * JD 解析结果。规则解析器和 AI 解析器都产出这个结构 —— 这就是"契约"。
 * AI 多给的字段会被忽略；缺的字段在紧凑构造器里兜底。
 */
@JsonIgnoreProperties(ignoreUnknown = true)
public record JdParsed(
        String jobTitle,
        List<SkillItem> requiredSkills,
        List<SkillItem> niceToHaveSkills,
        Integer minYearsExperience,
        String educationRequirement,
        List<String> responsibilities,
        List<String> keywords
) {
    public JdParsed {
        requiredSkills    = requiredSkills    == null ? List.of() : List.copyOf(requiredSkills);
        niceToHaveSkills  = niceToHaveSkills  == null ? List.of() : List.copyOf(niceToHaveSkills);
        responsibilities  = responsibilities  == null ? List.of() : List.copyOf(responsibilities);
        keywords          = keywords          == null ? List.of() : List.copyOf(keywords);
        minYearsExperience = minYearsExperience == null ? 0 : Math.max(0, minYearsExperience);
        educationRequirement = educationRequirement == null ? "NONE" : educationRequirement;
    }

    public boolean hasAnySkill() {
        return !requiredSkills.isEmpty() || !niceToHaveSkills.isEmpty();
    }
}
```

> **注意这个 record 里没有 `score` 字段**。这不是遗漏 —— 是故意的：AI 就算在 JSON 里输出 `"score": 100`，也会被 `@JsonIgnoreProperties` 丢掉，注入无处生效。**"结构上不允许"比"提示词里禁止"可靠得多。**

### 7.4.2 技能词典

```java
package com.jianli.ai.parser;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import jakarta.annotation.PostConstruct;
import lombok.Getter;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Component;

import java.io.InputStream;
import java.util.*;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Slf4j
@Component
@RequiredArgsConstructor
public class SkillDictionary {

    private static final Pattern ASCII_WORD = Pattern.compile("[a-z0-9][a-z0-9 .#+\\-]*");

    private final ObjectMapper objectMapper;

    private List<Entry> entries = List.of();
    private final Map<String, Entry> aliasIndex = new LinkedHashMap<>();

    @Getter
    public static class Entry {
        private String canonical;
        private List<String> aliases = List.of();
    }

    public record Match(String canonical, String matchedAlias, int start) {}

    @PostConstruct
    void load() {
        try (InputStream in = new ClassPathResource("dict/skills.json").getInputStream()) {
            entries = objectMapper.readValue(in, new TypeReference<List<Entry>>() {});
        } catch (Exception e) {
            log.error("技能词典加载失败，规则解析能力将受限", e);
            entries = List.of();
        }
        for (Entry e : entries) {
            aliasIndex.put(e.getCanonical().toLowerCase(Locale.ROOT), e);
            for (String a : e.getAliases()) {
                aliasIndex.put(a.toLowerCase(Locale.ROOT), e);
            }
        }
        log.info("技能词典加载完成：{} 个技能，{} 个别名", entries.size(), aliasIndex.size());
    }

    /** 在文本中找出所有技能（按别名匹配，ASCII 要求词边界，中文直接包含） */
    public List<Match> findAll(String text) {
        if (text == null || text.isBlank()) return List.of();
        String lower = text.toLowerCase(Locale.ROOT);
        List<Match> result = new ArrayList<>();

        for (Map.Entry<String, Entry> e : aliasIndex.entrySet()) {
            String alias = e.getKey();
            int from = 0;
            while (true) {
                int idx = lower.indexOf(alias, from);
                if (idx < 0) break;
                if (isBoundaryOk(text, idx, alias.length())) {
                    result.add(new Match(e.getValue().getCanonical(), alias, idx));
                }
                from = idx + alias.length();
            }
        }
        // 去重：同一 canonical 只保留第一次出现
        Map<String, Match> uniq = new LinkedHashMap<>();
        result.stream().sorted(Comparator.comparingInt(Match::start))
              .forEach(m -> uniq.putIfAbsent(m.canonical(), m));
        return new ArrayList<>(uniq.values());
    }

    /** ASCII 别名要求两侧不是字母数字，避免 "go" 命中 "algorithm" */
    private boolean isBoundaryOk(String text, int start, int len) {
        String alias = text.substring(start, start + len);
        if (!ASCII_WORD.matcher(alias.toLowerCase(Locale.ROOT)).matches()) return true;
        char before = start > 0 ? text.charAt(start - 1) : ' ';
        int afterIdx = start + len;
        char after = afterIdx < text.length() ? text.charAt(afterIdx) : ' ';
        return !Character.isLetterOrDigit(before) && !Character.isLetterOrDigit(after);
    }

    public boolean contains(String text, String canonical) {
        return findAll(text).stream().anyMatch(m -> m.canonical().equalsIgnoreCase(canonical));
    }

    public int size() { return entries.size(); }
}
```

> **`isBoundaryOk` 是关键**：没有它，`go` 会命中 `algorithm`、`java` 会命中 `javascript`。词边界判断是最省事的准确率提升手段。
> **词典加载失败不抛异常**：`catch` 后置空，规则解析降级到"零技能"，但**应用照常启动**。这符合"AI/词典都不是必需品"的原则。

### 7.4.3 规则解析器

```java
package com.jianli.ai.parser;

import com.jianli.ai.model.JdParsed;
import com.jianli.ai.model.SkillItem;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Component
@RequiredArgsConstructor
public class RuleJdParser {

    private static final Pattern YEARS_RANGE =
            Pattern.compile("(\\d{1,2})\\s*[-~至到]\\s*(\\d{1,2})\\s*年");
    private static final Pattern YEARS_MIN =
            Pattern.compile("(\\d{1,2})\\s*年(?:及)?以上");

    private static final List<String> HIGH_WORDS   = List.of("必须", "精通", "熟练掌握", "熟练使用", "扎实");
    private static final List<String> MEDIUM_WORDS = List.of("熟悉", "掌握", "具备", "经验");
    private static final List<String> LOW_WORDS    = List.of("优先", "加分", "了解", "者优先");

    private static final Map<String, String> CATEGORY = Map.ofEntries(
            Map.entry("Java", "LANGUAGE"), Map.entry("Python", "LANGUAGE"),
            Map.entry("Go", "LANGUAGE"), Map.entry("JavaScript", "LANGUAGE"),
            Map.entry("TypeScript", "LANGUAGE"), Map.entry("Spring Boot", "FRAMEWORK"),
            Map.entry("Spring Cloud", "FRAMEWORK"), Map.entry("Spring MVC", "FRAMEWORK"),
            Map.entry("MyBatis", "FRAMEWORK"), Map.entry("Hibernate", "FRAMEWORK"),
            Map.entry("Vue", "FRAMEWORK"), Map.entry("React", "FRAMEWORK"),
            Map.entry("MySQL", "DATABASE"), Map.entry("PostgreSQL", "DATABASE"),
            Map.entry("MongoDB", "DATABASE"), Map.entry("Redis", "MIDDLEWARE"),
            Map.entry("Kafka", "MIDDLEWARE"), Map.entry("RocketMQ", "MIDDLEWARE"),
            Map.entry("RabbitMQ", "MIDDLEWARE"), Map.entry("Elasticsearch", "MIDDLEWARE"),
            Map.entry("Docker", "TOOL"), Map.entry("Kubernetes", "TOOL"),
            Map.entry("Linux", "TOOL"), Map.entry("Nginx", "TOOL"),
            Map.entry("Git", "TOOL"), Map.entry("Maven", "TOOL"), Map.entry("Gradle", "TOOL"),
            Map.entry("分布式事务", "DOMAIN"), Map.entry("高并发", "DOMAIN"),
            Map.entry("微服务", "DOMAIN"), Map.entry("消息队列", "MIDDLEWARE"),
            Map.entry("缓存", "DOMAIN"), Map.entry("JVM调优", "DOMAIN"),
            Map.entry("多线程", "DOMAIN"),
            Map.entry("团队协作", "SOFT"), Map.entry("跨部门沟通", "SOFT")
    );

    private final SkillDictionary dictionary;

    public JdParsed parse(String jdText) {
        String text = jdText == null ? "" : jdText;
        String[] lines = text.split("\n");

        List<SkillItem> required = new ArrayList<>();
        List<SkillItem> nice = new ArrayList<>();
        Set<String> seen = new HashSet<>();

        for (SkillDictionary.Match m : dictionary.findAll(text)) {
            String line = lineOf(lines, m.start());
            String importance = judgeImportance(line);

            if (SkillItem.LOW.equals(importance) || line.contains("优先")) {
                nice.add(new SkillItem(m.canonical(), SkillItem.LOW, categoryOf(m.canonical())));
            } else if (seen.add(m.canonical())) {
                required.add(new SkillItem(m.canonical(), importance, categoryOf(m.canonical())));
            }
        }

        return new JdParsed(
                guessTitle(lines),
                required,
                nice,
                guessYears(text),
                guessEducation(text),
                guessResponsibilities(lines),
                guessKeywords(text)
        );
    }

    // ---------- 各个字段的抽取 ----------

    private String guessTitle(String[] lines) {
        for (String line : lines) {
            String t = line.trim();
            if (t.isEmpty() || t.length() > 40) continue;
            if (t.matches(".*(工程师|开发|架构师|专家|经理|分析师|实习生).*")) {
                return t.replaceAll("[（(].*?[)）]", "").trim();   // 去掉括号里的年限
            }
        }
        return null;
    }

    private int guessYears(String text) {
        Matcher range = YEARS_RANGE.matcher(text);
        if (range.find()) return Integer.parseInt(range.group(1));
        Matcher min = YEARS_MIN.matcher(text);
        if (min.find()) return Integer.parseInt(min.group(1));
        return 0;
    }

    private String guessEducation(String text) {
        if (text.contains("博士")) return "PHD";
        if (text.contains("硕士") || text.contains("研究生")) return "MASTER";
        if (text.contains("本科")) return "BACHELOR";
        if (text.contains("大专") || text.contains("专科")) return "ASSOCIATE";
        return "NONE";
    }

    private List<String> guessResponsibilities(String[] lines) {
        List<String> out = new ArrayList<>();
        for (String line : lines) {
            String t = line.trim().replaceAll("^[\\d一二三四五六七八九十]+[.、)）]\\s*", "");
            if (t.matches("^(负责|参与|主导|承担|配合).{4,40}")) {
                out.add(t.length() > 40 ? t.substring(0, 40) : t);
                if (out.size() >= 6) break;
            }
        }
        return out;
    }

    private List<String> guessKeywords(String text) {
        List<String> kw = new ArrayList<>();
        for (String w : List.of("高并发", "微服务", "分布式", "性能优化", "架构设计", "团队协作")) {
            if (text.contains(w)) kw.add(w);
        }
        return kw;
    }

    // ---------- 工具 ----------

    private String lineOf(String[] lines, int offset) {
        int acc = 0;
        for (String line : lines) {
            acc += line.length() + 1;
            if (offset < acc) return line;
        }
        return "";
    }

    private String judgeImportance(String line) {
        if (HIGH_WORDS.stream().anyMatch(line::contains)) return SkillItem.HIGH;
        if (LOW_WORDS.stream().anyMatch(line::contains)) return SkillItem.LOW;
        if (MEDIUM_WORDS.stream().anyMatch(line::contains)) return SkillItem.MEDIUM;
        return SkillItem.MEDIUM;
    }

    private String categoryOf(String canonical) {
        return CATEGORY.getOrDefault(canonical, "OTHER");
    }
}
```

> **`judgeImportance` 里先判 HIGH 再判 LOW**：因为"熟练掌握 X，有 Y 经验者优先"这种行里 HIGH 和 LOW 同时出现，技能 X 应该算 HIGH。
> 这套规则当然不完美（比如"了解 Redis 者优先"会进 nice），但它**可解释**：每一行都能告诉用户"为什么这样判"。

### 7.4.4 实体

```java
package com.jianli.jd.entity;

import jakarta.persistence.*;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

import java.time.LocalDateTime;
import java.time.ZoneOffset;

@Entity
@Table(name = "job_description")
@Getter
@Setter
@NoArgsConstructor
public class JobDescription {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(nullable = false, length = 100)
    private String title;

    @Column(length = 100)
    private String company;

    @Column(nullable = false, columnDefinition = "MEDIUMTEXT")
    private String content;

    @Column(name = "content_hash", nullable = false, length = 64)
    private String contentHash;

    /** NONE / PARSING / SUCCESS / FAILED */
    @Column(name = "parse_status", nullable = false, length = 16)
    private String parseStatus = "NONE";

    /** AI / RULE */
    @Column(name = "parsed_source", length = 8)
    private String parsedSource;

    /** 解析结果 JSON 快照 */
    @Column(name = "parsed_json", columnDefinition = "JSON")
    private String parsedJson;

    @Column(name = "parsed_at")
    private LocalDateTime parsedAt;

    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @Column(name = "updated_at", nullable = false)
    private LocalDateTime updatedAt;

    @PrePersist
    void onCreate() {
        LocalDateTime now = LocalDateTime.now(ZoneOffset.UTC);
        if (createdAt == null) createdAt = now;
        updatedAt = now;
    }

    @PreUpdate
    void onUpdate() { updatedAt = LocalDateTime.now(ZoneOffset.UTC); }
}
```

> `JSON` 列映射成 `String`，写入时用 `ObjectMapper.writeValueAsString`。为什么不用 Hibernate 的 `@JdbcTypeCode(SqlTypes.JSON)`？因为 MySQL 的 JSON 类型在各版本驱动下支持不一致，用 String 最稳，读写时自己做序列化。**"能用简单类型就别用特殊类型"**。

### 7.4.6 解析服务（把"结果存哪"这件事封装起来）

```java
package com.jianli.jd.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.jianli.ai.model.JdParsed;
import com.jianli.ai.parser.RuleJdParser;
import com.jianli.jd.entity.JobDescription;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.time.LocalDateTime;
import java.time.ZoneOffset;

@Slf4j
@Service
@RequiredArgsConstructor
public class JdParseService {

    /** 解析器版本：词典或规则改动时必须递增，缓存会随之失效 */
    public static final String PARSER_VERSION = "rule-v1";

    private final RuleJdParser ruleJdParser;
    private final ObjectMapper objectMapper;

    public ParsedResult parse(JobDescription jd) {
        JdParsed parsed = ruleJdParser.parse(jd.getContent());
        return new ParsedResult(parsed, "RULE");
    }

    public void applyResult(JobDescription jd, ParsedResult result) {
        try {
            jd.setParsedJson(objectMapper.writeValueAsString(result.data()));
            jd.setParsedSource(result.source());
            jd.setParseStatus("SUCCESS");
            jd.setParsedAt(LocalDateTime.now(ZoneOffset.UTC));
        } catch (Exception e) {
            log.error("JD 解析结果序列化失败, id={}", jd.getId(), e);
            jd.setParseStatus("FAILED");
        }
    }

    public record ParsedResult(JdParsed data, String source) {}
}
```

> 现在 `parse()` 只调规则；**步骤 10 会在这里插入"AI 优先、失败降级规则"**，而 `applyResult` 完全不用改 —— 这就是把"解析"和"落库"分开的好处。

`JdService`（关键部分）：

```java
@Service
@RequiredArgsConstructor
public class JdService {

    private static final int MIN_CHARS = 30;

    private final JobDescriptionRepository repository;
    private final JdParseService parseService;
    private final ResumeTextNormalizer normalizer;   // 复用步骤 5 的归一化
    private final ObjectMapper objectMapper;

    @Transactional
    public JdDetailVO create(Long userId, CreateJdRequest req) {
        String content = normalizer.normalize(req.content());
        if (normalizer.charCount(content) < MIN_CHARS) {
            throw new BizException(ErrorCode.JD_CONTENT_INVALID);
        }

        JobDescription jd = new JobDescription();
        jd.setUserId(userId);
        jd.setTitle(req.title());
        jd.setCompany(req.company());
        jd.setContent(content);
        jd.setContentHash(normalizer.sha256(content + "|" + JdParseService.PARSER_VERSION));
        jd = repository.save(jd);

        if (Boolean.TRUE.equals(req.parseNow())) {
            parseService.applyResult(jd, parseService.parse(jd));
        }
        return toDetail(jd);
    }

    @Transactional
    public JdDetailVO parse(Long userId, Long id, boolean force) {
        JobDescription jd = repository.findByIdAndUserId(id, userId)
                .orElseThrow(() -> new BizException(ErrorCode.JD_NOT_FOUND));

        if (!force && "SUCCESS".equals(jd.getParseStatus()) && jd.getParsedJson() != null) {
            return toDetail(jd);           // 已有结果，直接返回（步骤 10 会加 Redis 缓存）
        }
        parseService.applyResult(jd, parseService.parse(jd));
        return toDetail(jd);
    }

    /** 内容变更 → 解析结果作废 */
    @Transactional
    public JdDetailVO update(Long userId, Long id, CreateJdRequest req) {
        JobDescription jd = repository.findByIdAndUserId(id, userId)
                .orElseThrow(() -> new BizException(ErrorCode.JD_NOT_FOUND));

        String content = normalizer.normalize(req.content());
        if (normalizer.charCount(content) < MIN_CHARS) throw new BizException(ErrorCode.JD_CONTENT_INVALID);

        boolean changed = !content.equals(jd.getContent());
        jd.setTitle(req.title());
        jd.setCompany(req.company());
        jd.setContent(content);
        if (changed) {
            jd.setContentHash(normalizer.sha256(content + "|" + JdParseService.PARSER_VERSION));
            jd.setParsedJson(null);
            jd.setParsedSource(null);
            jd.setParseStatus("NONE");
            jd.setParsedAt(null);
        }
        return toDetail(jd);
    }
}
```

## 7.7 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 技能一个都抽不出来 | `skills.json` 没被打包 / 加载失败 | 看启动日志 `技能词典加载完成：N 个技能` |
| `javascript` 被判成 `Java` | 词边界失效 | 检查 `isBoundaryOk` |
| 全部技能都进加分项 | `line.contains("优先")` 太宽 | 只在 LOW 判定时看同一行，不要看整段文本 |
| `parsed_json` 写入报错 | 列类型不是 JSON 或字段过长 | 确认 DDL 里是 `JSON`；确保只存结构化结果不存原文 |
| 中文字符串在 JSON 里变成 `\uXXXX` | Jackson 默认转义 | 无碍；如果要可读，`application.yml` 加 `spring.jackson.generator.escape-non-ascii: false` |
| 修改 JD 后解析结果还在 | `update` 里没清空 | 检查 `changed` 分支 |

## 7.8 自测题

1. **为什么先做规则解析再做 AI？** → 规则是 AI 的降级目标，同时定义了输出契约；还能离线跑单测验证准确率。
2. **词典为什么要单独成 JSON？** → 一份数据服务四个模块，加技能不改代码，也是"AI 关闭时可用"的基础。
3. **重要度怎么判？** → 看技能所在行的修饰词（必须/精通 → HIGH，熟悉 → MEDIUM，优先/了解 → LOW）。
4. **为什么 niceToHave 要单独存？** → 它只参与加分项，不参与技能覆盖率分母，混在一起会把分数算低。
5. **为什么 JD 的 content_hash 要拼 parserVersion？** → 词典升级后旧缓存必须失效。
6. **为什么 record 里不放 score 字段？** → 从结构上杜绝 AI 打分，注入无处生效。
