# 步骤 06：版本对比（4 小时）

> **目标**：选两个版本，看到逐行的"新增 / 删除 / 未变"，以及字数变化。分数变化此时还没有（等步骤 9 有评分后自动补上）。
>
> 这一步是纯算法 + 纯展示，不涉及外部依赖，适合用来练"后端算、前端渲染"的分工。

## 6.2 为什么这样设计（面试可讲）

**① diff 为什么放后端算，不让前端算？**
- 前端算需要把两个版本的**全文**都拉到浏览器，简历文本可能上万字，来回传输和内存都没必要；
- 后端可以在同一个接口里顺便带上"分数变化"（步骤 9 之后），一次请求拿到完整对比结果；
- 算法只写一遍、只测一遍，换前端框架不用重写。

**② 为什么用 LCS（最长公共子序列），不用 Myers？**
Myers 是 Git 用的算法，最坏 O(ND)、在大文件上比 LCS 快得多，但实现复杂度明显更高。
本项目场景固定：**简历通常 50-200 行，我们还会把参与对比的行数限制在 500 行以内**。此时 LCS 的 O(n·m) = 500×500 = 25 万次比较，内存 250KB，耗时毫秒级 —— **性能完全不是瓶颈，可读性和可测试性才是**。
面试时这条要讲清楚：不是"不知道 Myers"，而是"在数据规模明确的前提下选了实现成本最低的方案"。

**③ 为什么按行比，不按字符比？**
简历对比的语义单位是"行"（一句话/一个条目）。按字符比会产生大量碎片化的红绿片段，用户根本看不出"我改了哪一条"。按行比的结果是"整行增 / 整行删"，正好对应"我把这条描述重写了"。

**④ 为什么要有 500 行上限？**
`dp[n+1][m+1]` 是二维数组，1000 行 × 1000 行 = 100 万个 int ≈ 4MB，单请求还能接受，但并发 50 个就是 200MB。**限制输入规模是最便宜的稳定性保障**。超过上限就直接取前 500 行对比，并在响应里返回 `truncated: true` 让前端提示。

**⑤ 为什么两个版本必须属于同一份简历？**
跨简历对比在语义上没意义（不同人的简历）。校验 `version.resumeId == resumeId`，不匹配返回 `40003 VERSION_MISMATCH`。
这也是一个**数据权限**检查：先确认这份简历属于当前用户，再确认两个版本都属于它。

**⑥ 分数差为什么要"可选"？**
分数来自"某版本 × 某 JD"的分析报告。如果两个版本从来没在同一个 JD 下分析过，就没有可比数据。所以 `scoreDelta` 设计为可空，前端显示"尚无对比数据，去分析"。**不要把"没有数据"编造成 0**。

package com.jianli.resume.diff;

public record DiffBlock(
        Type type,
        Integer baseLineNo,     // REMOVE/EQUAL 有值，ADD 为 null
        Integer targetLineNo,   // ADD/EQUAL 有值，REMOVE 为 null
        String text
) {

### 6.4.2 LCS 实现

```java
package com.jianli.resume.diff;

import java.util.ArrayList;
import java.util.List;

/**
 * 按行的 LCS diff。行数 ≤ MAX_LINES 时保证 O(n·m)，超出则截断。
 * 纯函数、无依赖，便于单测。
 */
public final class LineDiff {

    public static final int MAX_LINES = 500;

    private LineDiff() {}

    public record Result(List<DiffBlock> blocks, boolean truncated,
                         int addedLines, int removedLines, int unchangedLines) {}

    public static Result diff(String baseText, String targetText) {
        List<String> a = splitLines(baseText);
        List<String> b = splitLines(targetText);

        boolean truncated = false;
        if (a.size() > MAX_LINES) { a = a.subList(0, MAX_LINES); truncated = true; }
        if (b.size() > MAX_LINES) { b = b.subList(0, MAX_LINES); truncated = true; }

        int n = a.size(), m = b.size();
        int[][] dp = new int[n + 1][m + 1];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                dp[i][j] = a.get(i).equals(b.get(j))
                        ? dp[i + 1][j + 1] + 1
                        : Math.max(dp[i + 1][j], dp[i][j + 1]);
            }
        }

        List<DiffBlock> out = new ArrayList<>();
        int added = 0, removed = 0, unchanged = 0;
        int i = 0, j = 0;
        while (i < n && j < m) {
            if (a.get(i).equals(b.get(j))) {
                out.add(new DiffBlock(DiffBlock.Type.EQUAL, i + 1, j + 1, a.get(i)));
                unchanged++; i++; j++;
            } else if (dp[i + 1][j] >= dp[i][j + 1]) {
                out.add(new DiffBlock(DiffBlock.Type.REMOVE, i + 1, null, a.get(i)));
                removed++; i++;
            } else {
                out.add(new DiffBlock(DiffBlock.Type.ADD, null, j + 1, b.get(j)));
                added++; j++;
            }
        }
        while (i < n) {
            out.add(new DiffBlock(DiffBlock.Type.REMOVE, i + 1, null, a.get(i)));
            removed++; i++;
        }
        while (j < m) {
            out.add(new DiffBlock(DiffBlock.Type.ADD, null, j + 1, b.get(j)));
            added++; j++;
        }

        return new Result(List.copyOf(out), truncated, added, removed, unchanged);
    }

    private static List<String> splitLines(String text) {
        if (text == null || text.isEmpty()) return List.of();
        return List.of(text.split("\n", -1));
    }
}
```

> **`List.of(text.split(...))` 返回不可变列表**，后面 `subList` 也是视图，不会修改原数据。这里安全，因为我们只读。

### 6.4.4 Service

在 `ResumeService` 里加：

```java
@Transactional(readOnly = true)
public CompareResultVO compare(Long userId, Long resumeId,
                               Long baseVersionId, Long targetVersionId) {
    // ① 简历归属
    Resume resume = resumeRepository.findByIdAndUserId(resumeId, userId)
            .orElseThrow(() -> new BizException(ErrorCode.RESUME_NOT_FOUND));

    // ② 两个版本都必须属于这份简历（防跨简历对比）
    ResumeVersion base = versionRepository.findByIdAndResumeId(baseVersionId, resumeId)
            .orElseThrow(() -> new BizException(ErrorCode.VERSION_MISMATCH));
    ResumeVersion target = versionRepository.findByIdAndResumeId(targetVersionId, resumeId)
            .orElseThrow(() -> new BizException(ErrorCode.VERSION_MISMATCH));

    LineDiff.Result d = LineDiff.diff(base.getContent(), target.getContent());

    return new CompareResultVO(
            new CompareResultVO.VersionRef(base.getId(), base.getVersionNo()),
            new CompareResultVO.VersionRef(target.getId(), target.getVersionNo()),
            new CompareResultVO.Stats(d.addedLines(), d.removedLines(), d.unchangedLines(),
                    target.getCharCount() - base.getCharCount()),
            d.blocks(),
            d.truncated(),
            null            // 步骤 9 接入评分后：查两个版本在同一 JD 下的最新报告算差
    );
}
```

> `findByIdAndResumeId` 同时校验"存在"和"属于这份简历"，比先 `findById` 再判断更简洁 —— 而且不会泄露"这个版本 id 存在但属于别人"。

### 6.4.6 单测（算法的价值在这里体现）

```java
package com.jianli.resume.diff;

import org.junit.jupiter.api.Test;

import static org.assertj.core.api.Assertions.assertThat;

class LineDiffTest {

    @Test
    void 完全相同则全部EQUAL() {
        var r = LineDiff.diff("a\nb\nc", "a\nb\nc");
        assertThat(r.addedLines()).isZero();
        assertThat(r.removedLines()).isZero();
        assertThat(r.unchangedLines()).isEqualTo(3);
    }

    @Test
    void 新增一行() {
        var r = LineDiff.diff("a\nc", "a\nb\nc");
        assertThat(r.addedLines()).isEqualTo(1);
        assertThat(r.blocks().stream().filter(b -> b.type() == DiffBlock.Type.ADD)
                .findFirst().orElseThrow().text()).isEqualTo("b");
    }

    @Test
    void 删除一行() {
        var r = LineDiff.diff("a\nb\nc", "a\nc");
        assertThat(r.removedLines()).isEqualTo(1);
        assertThat(r.unchangedLines()).isEqualTo(2);
    }

    @Test
    void 整行替换算一增一删() {
        var r = LineDiff.diff("负责订单系统开发", "负责订单系统开发，QPS 提升至 1200");
        assertThat(r.addedLines()).isEqualTo(1);
        assertThat(r.removedLines()).isEqualTo(1);
    }

    @Test
    void 空文本不炸() {
        assertThat(LineDiff.diff("", "").blocks()).isEmpty();
        assertThat(LineDiff.diff(null, "a").addedLines()).isEqualTo(1);
    }

    @Test
    void 超过上限会截断() {
        String big = String.join("\n", java.util.Collections.nCopies(600, "x"));
        String big2 = String.join("\n", java.util.Collections.nCopies(600, "y"));
        var r = LineDiff.diff(big, big2);
        assertThat(r.truncated()).isTrue();
        assertThat(r.blocks()).hasSize(1000);   // 500 删 + 500 增
    }
}
```

> 这个测试类就是"为什么算法要写成纯静态函数"的答案：**不需要 Spring 上下文、不需要数据库、跑一次 20 毫秒**，改完算法立刻能验证。

## 6.7 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 对比页没内容 | 只有一个版本 | 先新增 v2 |
| 全是 REMOVE + 全是 ADD | 内容整体格式变了（如复制时换了换行） | 步骤 5 的归一化应已处理；检查是否历史数据是旧的 |
| 前端红绿显示错乱 | `blocks` 里 `text` 为空字符串被折叠 | CSS 里用 `' '` 兜底（已在 DiffViewer 处理） |
| 页面卡顿 | 版本特别长 | 截断逻辑已生效，检查返回的 `truncated` 是否为 true |
| `blocks` 顺序看不懂 | LCS 在"相同代价"时优先删除 | 这是算法选择，可接受；如需"先增后删"把比较改成 `>` |

## 6.8 自测题

1. **为什么不实现 Myers？** → 数据规模固定且小（≤500 行），LCS 的 O(n·m) 足够，实现和测试成本低得多。
2. **为什么限制 500 行？** → 二维 DP 的内存是 n×m，限制输入是最便宜的稳定性保障。
3. **为什么按行不比字符？** → 简历的语义单位是行，行级 diff 才能表达"我重写了这条描述"。
4. **`scoreDelta` 为什么可空？** → 没有共同 JD 的分析结果就没有可比分数，不能编造成 0。
5. **对比接口怎么防越权？** → 先校验简历归属，再用 `findByIdAndResumeId` 保证两个版本都属于它。
