# 步骤 08：简历规则解析 + 分析任务骨架（5 小时）

> **目标**：点"发起分析"，后端异步跑完"解析 JD → 解析简历 → 落库"，报告状态从 `PENDING → RUNNING → SUCCESS`。此时还没有分数（步骤 9 才有），但**整条异步链路和事务边界已经跑通**。
>
> 先把"任务跑得起来"和"算得对"分成两步，出问题时能立刻判断是调度问题还是算法问题。

## 8.1 这一步做出什么

| 场景 | 行为 |
|---|---|
| 发起分析 | `POST /api/analyses {resumeVersionId, jdId}` → 202 + `reportId` |
| 立即查询 | `GET /api/analyses/{id}` → `status=PENDING` 或 `RUNNING` |
| 几百毫秒后 | `status=SUCCESS`，`resumeParsedJson` / `jdParsedJson` 有值 |
| 重复发起同一对 | 命中 `cacheKey`，直接返回旧报告（不重复算） |
| 简历/JD 不属于我 | 403 / 404 |
| 分析失败 | `status=FAILED`，`errorMessage` 有原因，服务不崩 |

## 8.2 为什么这样设计（面试可讲）

**① 为什么分析要异步？**
一次分析要调 1-3 次 AI（JD 解析、简历解析、语义匹配、建议），实测 5-10 秒。如果同步返回：
- 用户盯着转圈 10 秒，中途刷新就前功尽弃；
- Tomcat 线程被占 10 秒，50 个并发就把线程池打满，**静态资源接口都跟着超时**。

异步之后：HTTP 线程只负责"接单 + 返回 202 + reportId"，几十毫秒就释放；真正的活在独立线程池里跑。

**② 为什么用独立线程池，不复用 Tomcat 的？**
Tomcat 默认 200 个线程，是给"短请求"用的。AI 调用是**慢且阻塞**的（IO 等待），混在一起会导致：10 个慢任务就能拖住整个应用。
所以 `analysisExecutor` 单独配置（core 4 / max 8 / queue 50），即使慢任务堆积，也只是"分析排队"，不影响登录、浏览等正常请求。

**③ 为什么用数据库的 status 字段做状态机，不用"内存里跑没跑完"？**
内存状态在重启后丢失、多实例时不共享、用户刷新页面也读不到。落库后：
- 用户随时可以查 `GET /api/analyses/{id}`；
- 服务重启后能看到"有 PENDING/RUNNING 的残留任务"（可以做补偿，本项目手动重试）；
- 前端能做进度条（步骤 11 的 SSE 读的就是这个状态）。

**④ 为什么要有 `PENDING` 和 `RUNNING` 两个状态？**
`PENDING` 是"已入库、还没开始跑"（线程池排队中）；`RUNNING` 是"正在跑"。区分它们才能回答"是排队慢还是执行慢"。任务开始时先 `markRunning` 再干活，是异步任务的标准套路。

**⑤ `@Async` 有哪些坑？（这段面试常被追问）**
1. **同类自调用失效**：在 `AnalysisService` 里 `this.runAsync()` 不走代理，等于同步执行。所以异步方法必须放在**另一个 Bean**（`AnalysisAsyncService`）里。
2. **拿不到请求线程的事务**：请求已经返回了，事务早提交了。异步方法必须自己开事务（`@Transactional` 在这个方法上，或手动 `TransactionTemplate`）。
3. **异常被吞**：异步方法抛异常不会传回调用方，必须在方法内 try/catch 并更新状态，否则报告永远卡在 `RUNNING`。
4. **线程池满**：`AbortPolicy` 会让 `@Async` 直接抛 `TaskRejectedException`，所以提交前要判断，或者用 `CallerRunsPolicy` 降级在调用线程执行。

**⑥ 为什么报告要存 `jd_parsed_json` 和 `resume_parsed_json` 快照？**
解析结果会随时间变化（词典更新、模型升级、AI 输出不稳定）。报告里存一份快照，三个月后回看时：**用户看到的就是当时算分用的那份数据**。这是"可解释"的前提，也是步骤 9 能给出"为什么这 7 个技能命中 4 个"的依据。

**⑦ 为什么要 `cacheKey` 复用已算好的报告？**
用户手滑点两次、或者来回切页面重试，都会重复触发分析。`cacheKey = sha256(版本id | JD id | 评分版本 | AI 开关 | JD hash | 简历 hash)`，命中就直接返回旧报告。
注意 key 里**必须包含 AI 开关和算法版本** —— 否则关了 AI 还能拿到 AI 算的结果，或者算法升级后拿到旧分。

**⑧ 规则解析的边界在哪？（诚实地说清楚）**
规则解析做不到"理解语义"：它不认识"带过 5 人团队"这种非结构化描述，也读不出项目里的隐含职责。它擅长的是**有明确模式的东西**：技能名、时间区间、学历关键词、量化数字、板块标题。
所以它适合做"降级方案"和"评分的主要输入"，而"改写成什么样"必须交给 AI。**知道自己工具的边界，比吹它万能更重要。**

```java
        experiences     = experiences     == null ? List.of() : List.copyOf(experiences);
        projects        = projects        == null ? List.of() : List.copyOf(projects);
        sectionsPresent = sectionsPresent == null ? List.of() : List.copyOf(sectionsPresent);

        totalYears      = totalYears == null ? 0.0 : totalYears;

    @JsonIgnoreProperties(ignoreUnknown = true)
```

### 8.4.2 规则解析器

```java
package com.jianli.ai.parser;

import com.jianli.ai.model.ResumeParsed;
import com.jianli.ai.model.ResumeParsed.*;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Component
@RequiredArgsConstructor
public class RuleResumeParser {

    private static final Map<String, String> SECTION_KEYWORDS = Map.of(
            "BASIC_INFO", "个人信息|基本信息|求职意向|联系方式",
            "EDUCATION",  "教育背景|教育经历|学历",
            "SKILLS",     "专业技能|技能清单|技术栈|掌握技能|技能特长",
            "EXPERIENCE", "工作经历|工作经验|实习经历|职业经历",
            "PROJECT",    "项目经历|项目经验|项目实践"
    );

    /** 2022.07 - 2024.06 / 2022年7月-2024年6月 */
    private static final Pattern PERIOD = Pattern.compile(
            "(\\d{4})\\s*[./年-]\\s*(\\d{1,2})?\\s*[./月]?\\s*[~\\-—至到]+\\s*(\\d{4}|至今|现在)\\s*[./年-]?\\s*(\\d{1,2})?");

    /** 量化表达：数字 + 单位 */
    private static final Pattern QUANTIFIED = Pattern.compile(
            "\\d+(?:\\.\\d+)?\\s*(?:%|％|万|千|倍|ms|s|QPS|TPS|条|个|人|次|天|小时|单|元)");

    private final SkillDictionary dictionary;

    public ResumeParsed parse(String content) {
        String text = content == null ? "" : content;
        String[] lines = text.split("\n");

        List<String> sections = detectSections(lines);
        List<ResumeSkill> skills = extractSkills(text);
        List<ExperienceItem> experiences = extractExperiences(lines, sections);
        List<ProjectItem> projects = extractProjects(lines, sections);
        Education education = extractEducation(text);

        return new ResumeParsed(skills, experiences, projects, education,
                sections, totalYears(experiences), List.of());
    }

    // ---------- 板块识别 ----------
    private List<String> detectSections(String[] lines) {
        List<String> found = new ArrayList<>();
        for (Map.Entry<String, String> e : SECTION_KEYWORDS.entrySet()) {
            Pattern p = Pattern.compile("^\\s*(?:" + e.getValue() + ")", Pattern.CASE_INSENSITIVE);
            if (Arrays.stream(lines).anyMatch(l -> p.matcher(l).find())) {
                found.add(e.getKey());
            }
        }
        return found;
    }

    // ---------- 技能（复用 JD 的词典，证据取所在行）----------
    private List<ResumeSkill> extractSkills(String text) {
        String[] lines = text.split("\n");
        List<ResumeSkill> out = new ArrayList<>();
        for (SkillDictionary.Match m : dictionary.findAll(text)) {
            String line = lineAt(lines, m.start());
            String evidence = line.length() > 60 ? line.substring(0, 60) : line;
            out.add(new ResumeSkill(m.canonical(), evidence.trim()));
        }
        return out;
    }

    // ---------- 工作经历 ----------
    private List<ExperienceItem> extractExperiences(String[] lines, List<String> sections) {
        if (!sections.contains("EXPERIENCE")) return List.of();

        int start = indexOfSection(lines, "EXPERIENCE");
        int end = nextSectionIndex(lines, start);
        List<ExperienceItem> out = new ArrayList<>();

        ExperienceItem current = null;
        List<Bullet> bullets = new ArrayList<>();

        for (int i = start + 1; i < end; i++) {
            String line = lines[i].trim();
            if (line.isEmpty()) continue;

            Matcher m = PERIOD.matcher(line);
            if (m.find()) {
                if (current != null) out.add(withBullets(current, bullets));
                bullets = new ArrayList<>();
                current = new ExperienceItem(
                        line.substring(0, m.start()).trim(),   // 职位+公司
                        null, m.group(), monthsOf(m), List.of());
            } else if (current != null && line.length() > 4) {
                bullets.add(new Bullet(line, QUANTIFIED.matcher(line).find()));
            }
        }
        if (current != null) out.add(withBullets(current, bullets));
        return out;
    }

    private ExperienceItem withBullets(ExperienceItem e, List<Bullet> bullets) {
        return new ExperienceItem(e.title(), e.org(), e.period(), e.totalMonths(), bullets);
    }

    private int monthsOf(Matcher m) {
        int startYear = Integer.parseInt(m.group(1));
        int startMonth = m.group(2) == null ? 1 : Integer.parseInt(m.group(2));
        int endYear;
        int endMonth;
        String endRaw = m.group(3);
        if ("至今".equals(endRaw) || "现在".equals(endRaw)) {
            java.time.LocalDate now = java.time.LocalDate.now();
            endYear = now.getYear();
            endMonth = now.getMonthValue();
        } else {
            endYear = Integer.parseInt(endRaw);
            endMonth = m.group(4) == null ? 12 : Integer.parseInt(m.group(4));
        }
        int months = (endYear - startYear) * 12 + (endMonth - startMonth);
        return Math.max(months, 0);
    }

    // ---------- 项目 ----------
    private List<ProjectItem> extractProjects(String[] lines, List<String> sections) {
        if (!sections.contains("PROJECT")) return List.of();

        int start = indexOfSection(lines, "PROJECT");
        int end = nextSectionIndex(lines, start);
        List<ProjectItem> out = new ArrayList<>();

        for (int i = start + 1; i < end; i++) {
            String line = lines[i].trim();
            if (line.isEmpty()) continue;
            boolean looksLikeTitle = line.length() <= 30 && !line.startsWith("-") && !line.startsWith("·");
            if (looksLikeTitle && out.size() < 6) {
                boolean quantified = false;
                String desc = "";
                for (int j = i + 1; j < end; j++) {
                    String next = lines[j].trim();
                    if (next.isEmpty()) continue;
                    if (QUANTIFIED.matcher(next).find()) quantified = true;
                    if (desc.isEmpty() && next.length() > 8) desc = next;
                }
                List<String> tech = dictionary.findAll(line).stream()
                        .map(SkillDictionary.Match::canonical).toList();
                out.add(new ProjectItem(line, tech, desc, quantified));
            }
        }
        return out;
    }

    // ---------- 教育 ----------
    private Education extractEducation(String text) {
        String degree = text.contains("博士") ? "PHD"
                : text.contains("硕士") || text.contains("研究生") ? "MASTER"
                : text.contains("本科") ? "BACHELOR"
                : text.contains("大专") || text.contains("专科") ? "ASSOCIATE"
                : "NONE";

        Matcher school = Pattern.compile("([\\u4e00-\\u9fa5]{2,15}(?:大学|学院|学校))").matcher(text);
        Matcher major = Pattern.compile("(计算机[\\u4e00-\\u9fa5]{0,8}|软件工程|电子信息|通信工程|信息管理)").matcher(text);

        return new Education(degree,
                school.find() ? school.group(1) : null,
                major.find() ? major.group(1) : null);
    }

    // ---------- 年限 ----------
    /** 简化实现：取所有经历中最早开始到最晚结束的跨度（不处理并行/重叠） */
    private double totalYears(List<ExperienceItem> experiences) {
        if (experiences.isEmpty()) return 0.0;
        int months = experiences.stream().mapToInt(ExperienceItem::totalMonths).sum();
        return Math.round(months / 12.0 * 10) / 10.0;
    }

    // ---------- 工具 ----------
    private int indexOfSection(String[] lines, String section) {
        String kw = SECTION_KEYWORDS.get(section);
        Pattern p = Pattern.compile("^\\s*(?:" + kw + ")");
        for (int i = 0; i < lines.length; i++) {
            if (p.matcher(lines[i]).find()) return i;
        }
        return -1;
    }

    private int nextSectionIndex(String[] lines, int from) {
        for (int i = from + 1; i < lines.length; i++) {
            String l = lines[i];
            for (String kw : SECTION_KEYWORDS.values()) {
                if (Pattern.compile("^\\s*(?:" + kw + ")").matcher(l).find()) return i;
            }
        }
        return lines.length;
    }

    private String lineAt(String[] lines, int offset) {
        int acc = 0;
        for (String line : lines) {
            acc += line.length() + 1;
            if (offset < acc) return line;
        }
        return "";
    }
}
```

> `totalYears` 是**简化实现**（直接加总所有经历的月数），重叠经历会算多。真实产品应该合并时间区间。文档里刻意保留这个简化并标注，面试时主动说出"我知道这里不严谨，正确的做法是区间合并"反而加分。

```java
    @Column(name = "cache_key", nullable = false, length = 64)
    private String cacheKey;

    @Column(name = "duration_ms")
    private Integer durationMs;

    @Column(name = "error_message", length = 500)
    private String errorMessage;

    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @Column(name = "updated_at", nullable = false)
    private LocalDateTime updatedAt;

        LocalDateTime now = LocalDateTime.now(ZoneOffset.UTC);
        if (createdAt == null) createdAt = now;
        updatedAt = now;
    }

    @PreUpdate
    void onUpdate() { updatedAt = LocalDateTime.now(ZoneOffset.UTC); }
}
```

### 8.4.5 线程池

```java
package com.jianli.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor;

import java.util.concurrent.ThreadPoolExecutor;

@Configuration
public class AsyncConfig {

    @Bean("analysisExecutor")
    public ThreadPoolTaskExecutor analysisExecutor() {
        ThreadPoolTaskExecutor ex = new ThreadPoolTaskExecutor();
        ex.setCorePoolSize(4);
        ex.setMaxPoolSize(8);
        ex.setQueueCapacity(50);
        ex.setThreadNamePrefix("analysis-");
        // 队列满时抛异常，让调用方收到明确反馈，而不是无限堆积
        ex.setRejectedExecutionHandler(new ThreadPoolExecutor.AbortPolicy());
        ex.setWaitForTasksToCompleteOnShutdown(true);
        ex.setAwaitTerminationSeconds(30);
        ex.initialize();
        return ex;
    }
}
```

### 8.4.6 同步服务：创建与查询

```java
package com.jianli.analysis.service;

import com.jianli.analysis.entity.AnalysisReport;
import com.jianli.analysis.repository.AnalysisReportRepository;
import com.jianli.common.*;
import com.jianli.config.AiProperties;
import com.jianli.jd.entity.JobDescription;
import com.jianli.jd.repository.JobDescriptionRepository;
import com.jianli.resume.entity.ResumeVersion;
import com.jianli.resume.service.ResumeService;
import com.jianli.resume.service.ResumeTextNormalizer;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.core.task.TaskRejectedException;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Slf4j
@Service
@RequiredArgsConstructor
public class AnalysisService {

    public static final String SCORING_VERSION = "v1";
    private static final List<String> DONE = List.of("SUCCESS", "PARTIAL");

    private final AnalysisReportRepository reportRepository;
    private final AnalysisAsyncService asyncService;
    private final ResumeService resumeService;
    private final JobDescriptionRepository jdRepository;
    private final ResumeTextNormalizer normalizer;
    private final AiProperties aiProperties;

    @Transactional
    public CreateResult create(Long userId, Long resumeVersionId, Long jdId, boolean forceRefresh) {
        ResumeVersion version = resumeService.requireOwnedVersion(userId, resumeVersionId);
        JobDescription jd = jdRepository.findByIdAndUserId(jdId, userId)
                .orElseThrow(() -> new BizException(ErrorCode.JD_NOT_FOUND));

        String cacheKey = normalizer.sha256(String.join("|",
                String.valueOf(resumeVersionId), String.valueOf(jdId),
                SCORING_VERSION, String.valueOf(aiProperties.enabled()),
                jd.getContentHash(), version.getContentHash()));

        if (!forceRefresh) {
            var cached = reportRepository
                    .findFirstByCacheKeyAndStatusInOrderByIdDesc(cacheKey, DONE);
            if (cached.isPresent()) {
                return new CreateResult(cached.get().getId(), cached.get().getStatus(), true);
            }
        }

        AnalysisReport report = new AnalysisReport();
        report.setUserId(userId);
        report.setResumeVersionId(resumeVersionId);
        report.setJdId(jdId);
        report.setStatus("PENDING");
        report.setScoringVersion(SCORING_VERSION);
        report.setAiEnabled(aiProperties.enabled());
        report.setCacheKey(cacheKey);
        report = reportRepository.save(report);

        try {
            asyncService.run(report.getId());
        } catch (TaskRejectedException e) {
            report.setStatus("FAILED");
            report.setErrorMessage("分析任务队列已满，请稍后重试");
            throw new BizException(ErrorCode.TOO_MANY_REQUESTS);
        }

        return new CreateResult(report.getId(), "PENDING", false);
    }

    @Transactional(readOnly = true)
    public AnalysisReport getOwned(Long userId, Long reportId) {
        return reportRepository.findByIdAndUserId(reportId, userId)
                .orElseThrow(() -> new BizException(ErrorCode.ANALYSIS_NOT_FOUND));
    }

    public record CreateResult(Long reportId, String status, boolean cached) {}
}
```

> **为什么 catch `TaskRejectedException` 后还要把状态改成 FAILED**：任务没跑起来，报告就会永远 PENDING。要么改 FAILED 让用户重试，要么删掉这条记录。这里选前者（保留痕迹便于排查）。

### 8.4.7 异步执行

```java
package com.jianli.analysis.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.jianli.ai.model.JdParsed;
import com.jianli.ai.model.ResumeParsed;
import com.jianli.ai.parser.RuleResumeParser;
import com.jianli.analysis.entity.AnalysisReport;
import com.jianli.analysis.repository.AnalysisReportRepository;
import com.jianli.jd.entity.JobDescription;
import com.jianli.jd.repository.JobDescriptionRepository;
import com.jianli.jd.service.JdParseService;
import com.jianli.resume.entity.ResumeVersion;
import com.jianli.resume.repository.ResumeVersionRepository;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Slf4j
@Service
@RequiredArgsConstructor
public class AnalysisAsyncService {

    private final AnalysisReportRepository reportRepository;
    private final ResumeVersionRepository versionRepository;
    private final JobDescriptionRepository jdRepository;
    private final JdParseService jdParseService;
    private final RuleResumeParser ruleResumeParser;
    private final ObjectMapper objectMapper;

    /** 必须是独立的 Bean，否则 @Async 不生效（同类自调用走不到代理） */
    @Async("analysisExecutor")
    public void run(Long reportId) {
        long start = System.currentTimeMillis();
        markRunning(reportId);

        try {
            AnalysisReport report = reportRepository.findById(reportId).orElseThrow();
            ResumeVersion version = versionRepository.findById(report.getResumeVersionId()).orElseThrow();
            JobDescription jd = jdRepository.findById(report.getJdId()).orElseThrow();

            // ① JD 解析（已解析过就复用）
            JdParsed jdParsed = readJdParsed(jd)
                    .orElseGet(() -> {
                        JdParsed p = jdParseService.parse(jd).data();
                        return p;
                    });

            // ② 简历解析（规则版，步骤 10 会换成 AI 优先）
            ResumeParsed resumeParsed = ruleResumeParser.parse(version.getContent());

            // ③ 落库（步骤 9 这里会加评分）
            saveSuccess(report, jdParsed, resumeParsed, start);

        } catch (Exception e) {
            log.error("分析失败 reportId={}", reportId, e);
            markFailed(reportId, e.getMessage());
        }
    }

    @Transactional
    protected void markRunning(Long reportId) {
        reportRepository.findById(reportId).ifPresent(r -> r.setStatus("RUNNING"));
    }

    @Transactional
    protected void saveSuccess(AnalysisReport report, JdParsed jdParsed,
                               ResumeParsed resumeParsed, long start) {
        report.setJdParsedJson(toJson(jdParsed));
        report.setResumeParsedJson(toJson(resumeParsed));
        report.setStatus("SUCCESS");
        report.setDegraded(false);
        report.setDurationMs((int) (System.currentTimeMillis() - start));
        reportRepository.save(report);
    }

    @Transactional
    protected void markFailed(Long reportId, String message) {
        reportRepository.findById(reportId).ifPresent(r -> {
            r.setStatus("FAILED");
            r.setErrorMessage(message == null ? "unknown" :
                    message.substring(0, Math.min(message.length(), 500)));
        });
    }

    private java.util.Optional<JdParsed> readJdParsed(JobDescription jd) {
        if (jd.getParsedJson() == null) return java.util.Optional.empty();
        try {
            return java.util.Optional.of(objectMapper.readValue(jd.getParsedJson(), JdParsed.class));
        } catch (Exception e) {
            return java.util.Optional.empty();
        }
    }

    private String toJson(Object o) {
        try {
            return objectMapper.writeValueAsString(o);
        } catch (Exception e) {
            return "{}";
        }
    }
}
```

> ⚠️ **`protected` + `@Transactional` 的自调用陷阱**：`run()` 里调 `this.markRunning()` 不会走代理，`@Transactional` 不生效（但因为是同一个 Hibernate Session，仍然能写入 —— 只是没有独立事务控制）。
> 更严谨的写法是把这三个方法放到一个独立 Bean（如 `AnalysisReportWriter`），或使用 `TransactionTemplate`。**文档这里故意保留简单写法，但你要知道它的边界**；面试被问到"事务怎么传播的"时要能说清楚。

## 8.6 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 报告一直 `PENDING` | `@Async` 没生效（同类自调用） | 异步方法必须在独立 Bean（`AnalysisAsyncService`） |
| 报告一直 `RUNNING` | 异步方法里抛异常但没更新状态 | 确认 try/catch 包住整个流程并调 `markFailed` |
| `TaskRejectedException` | 队列满（50） | 正常现象；降低并发或调大队列 |
| 启动报 `No qualifying bean of type TaskExecutor` | `@EnableAsync` 缺 | 启动类加注解 |
| JD 解析结果为空 | JD 没解析过且规则抽不出 | `readJdParsed` 已兜底调用规则解析；确认词典加载成功 |
| 时间戳差 8 小时 | 时区 | 统一 `ZoneOffset.UTC` + 前端换 GMT+8 |
| `cached=true` 但分数是旧的 | cacheKey 没含算法版本 | 已在 key 里含 `SCORING_VERSION` 和 `aiEnabled` |

## 8.7 自测题

1. **为什么分析要异步，为什么用独立线程池？** → AI 慢且阻塞，占用 Tomcat 线程会拖垮全站；独立池只影响分析排队。
2. **`@Async` 的四个坑？** → 同类自调用失效、拿不到请求事务、异常被吞、线程池拒绝。
3. **为什么状态要落库？** → 重启不丢、多实例共享、前端可查进度。
4. **`cacheKey` 里为什么必须包含 AI 开关和算法版本？** → 否则关了 AI 还能拿到 AI 结果、算法升级后拿到旧分。
5. **报告为什么要存解析快照？** → 可复现、可解释，几个月后回看仍是当时的数据。
6. **规则解析的边界在哪？** → 只能抽有明确模式的信息（技能/年限/学历/量化/板块），理解语义必须靠 AI。
