# 步骤 12：个人信息审核与发帖（7 小时）

> **目标**：带手机号的简历点"发布"→ **HTTP 422 + code 43002**，前端弹出对话框并**高亮定位到那一行**；用户抹掉后重新提交 → 发布成功；审核记录落库（**但不存原文**）。
>
> 这是社区模块的地基，也是全项目最"有产品思维"的一块。

---

## 12.1 这一步做出什么

| 场景 | 行为 |
|---|---|
| 简历含 `13800138000` | 422 + `code=43002`，`hits` 里给出类型、位置、**脱敏片段**、建议 |
| 含 `138-0013-8000` | 同样命中（归一化后匹配，位置映射回原文） |
| 含身份证（校验位合法） | 命中 `ID_CARD` |
| 含 `订单号 202311010000000001` | **不**命中（校验位不通过） |
| 含"杭州市" | **不**命中（无门牌结构） |
| 含"杭州市西湖区文三路 123 号 5 幢 302 室" | 命中 `ADDRESS` |
| 预检接口 | 只返回结果，**不落库** |
| 正式发帖 | 落 `privacy_review`（PASSED 或 REJECTED），通过才建 `post` |
| 评论 | 同样审核 |
| AI 关闭 | 审核**完全不受影响**（本来就不依赖 AI） |

---

## 12.2 为什么这样设计（面试可讲）

**① 为什么用规则而不是让 AI 判断？**

| 维度 | 规则 | AI |
|---|---|---|
| 确定性 | 手机号就是 11 位 `1[3-9]` 开头 | 同一输入可能给出不同结论 |
| 延迟 | 1-3ms | 2-10s |
| 可审计 | "规则 v1、PHONE、偏移 132-143" 可复核 | 无法复核 |
| 隐私自洽 | 全程本地，原文不出网 | **审核者本身把含身份证的文本发给了第三方** |
| 可测试 | 正反例各 20 条跑单测 | 写不了断言 |
| 可用性 | 不受网络/额度影响 | Key 过期就失效 |

**最关键的是第四条**：审核的目的就是"不要把个人信息发出去"，如果审核过程把原文发给大模型，逻辑上自相矛盾 —— 数据已经出网了。

**② 为什么规则要"归一化后再匹配"？**
用户会写 `138-0013-8000`、`138 0013 8000`、全角 `１３８００１３８０００`。直接在原文上跑正则，这三种全都漏。
所以先归一化（全角转半角、吞掉数字之间的空格和短横线），再匹配 —— 同时维护 `indexMap`（归一化下标 → 原文下标），把命中位置**映射回原文**，前端才能高亮。

**③ 为什么要做"二次校验"？**
纯正则误报率太高：
- 18 位数字不一定是身份证（订单号、项目编号）；
- 16-19 位数字不一定是银行卡；
- 有"市/区"不一定是住址（"我在杭州工作"）。

所以加校验：
- 身份证：ISO 7064 MOD 11-2 **校验位** + 出生日期合法性；
- 银行卡：**Luhn 校验**；
- 住址：必须"行政区划链 **且** 门牌号"两个条件同时满足。

**这是把误报率从"每天几十个用户被无端拒绝"降到接近零的关键。**

**④ 为什么明确不检测姓名？**
中文姓名无法可靠正则化（"张三"可能是公司名、项目名、技术名词）。误报后会给出用户无法理解的拒绝理由（"你的简历里有敏感信息：张三"），体验极差。
所以产品上**明确告知**："发布前请自行确认姓名、公司内部信息是否需要替换" —— **把无法自动判断的边界说清楚，比假装能检测更负责任。**

**⑤ 为什么命中任意一条就拒绝，不设"允许 1-2 条"？**
简历里的手机号就是求职者的真实联系方式。没有"轻微泄露"这种说法。设阈值会让"多写一个号码才被拦"显得荒谬。用户抹掉的成本很低（前端已高亮定位）。

**⑥ 为什么审核记录要单独一张表，而且"拒绝"也要落库？**
- 合规与审计：要能回答"这条帖子发布时审核过吗"；
- 规则调优：统计各类敏感信息的命中量，判断是否误杀（某类突然暴增 = 规则太宽）；
- **拒绝记录必须独立事务**（`REQUIRES_NEW`），否则发帖失败回滚时审计记录也没了。

**⑦ 为什么审核记录里"不存原文"？**
如果为了审计把原文写进 `privacy_review`，那数据库里就永久多了一份敏感信息副本 —— 和"不要泄露"的初衷冲突。
所以只存 `content_hash`（用于关联，不可逆）+ 脱敏片段（`138****5678`）。

**⑧ 为什么前端检查了，服务端还要再查一遍？**
前端检查只是**体验优化**（快速反馈），**不是安全边界**。用户可以直接调接口、或者改前端代码绕过。所以服务端必须独立审核，且以服务端结果为准。

**⑨ 为什么"预检"用 HTTP 200 + `passed:false`，而"发布失败"用 422？**
语义不同：预检是"查询这次内容是否符合规范"，查询成功就是 200；发布是"创建资源失败"，属于不可处理的内容 → 422。
前端拦截器也因此能区分：43002 不弹通用提示，交给页面做高亮对话框。

### 12.4.2 归一化 + 下标映射（**最容易写错的地方**）

```java
package com.jianli.privacy;

public record NormalizedText(String text, int[] indexMap, String raw) {

    /** 归一化：全角→半角，吞掉数字之间用于分隔的空格/短横线 */
    public static NormalizedText of(String raw) {
        String src = raw == null ? "" : raw;
        StringBuilder sb = new StringBuilder(src.length());
        int[] map = new int[src.length() + 1];

        for (int i = 0; i < src.length(); i++) {
            char c = src.charAt(i);
            char n = toHalfWidth(c);

            boolean isSep = (n == ' ' || n == '-' || n == '　');
            if (isSep && sb.length() > 0 && i + 1 < src.length()
                    && Character.isDigit(sb.charAt(sb.length() - 1))
                    && Character.isDigit(toHalfWidth(src.charAt(i + 1)))) {
                continue;   // 数字串中间的分隔符吞掉，但 indexMap 不变
            }
            map[sb.length()] = i;
            sb.append(n);
        }
        map[sb.length()] = src.length();
        return new NormalizedText(sb.toString(), map, src);
    }

    /** 归一化区间 → 原文区间 */
    public int[] toOriginalRange(int start, int end) {
        int s = indexMap[start];
        int e = indexMap[Math.min(end, indexMap.length - 1)];
        return new int[]{s, Math.max(e, s + 1)};
    }

    private static char toHalfWidth(char c) {
        if (c == '　') return ' ';
        if (c >= '０' && c <= '９') return (char) (c - '０' + '0');
        if (c >= 'Ａ' && c <= 'Ｚ') return (char) (c - 'Ａ' + 'A');
        if (c >= 'ａ' && c <= 'ｚ') return (char) (c - 'ａ' + 'a');
        if (c == '＠') return '@';
        if (c == '．') return '.';
        if (c == '－') return '-';
        return c;
    }
}
```

> **`map` 的最后一个元素**必须单独设成 `src.length()`，否则"命中到字符串末尾"时会越界或截错。

### 12.4.3 脱敏

```java
package com.jianli.privacy;

public final class Masker {

    private Masker() {}

    public static String mask(SensitiveType type, String value) {
        if (value == null || value.isEmpty()) return "***";
        return switch (type) {
            case PHONE -> value.length() >= 7
                    ? value.substring(0, 3) + "****" + value.substring(value.length() - 4)
                    : "***";
            case ID_CARD -> value.length() >= 8
                    ? value.substring(0, 4) + "**********" + value.substring(value.length() - 4)
                    : "***";
            case EMAIL -> {
                int at = value.indexOf('@');
                yield at > 1 ? value.substring(0, 2) + "***" + value.substring(at) : "***";
            }
            case ADDRESS -> value.length() > 6 ? value.substring(0, 6) + "***" : "***";
            case BANK_CARD -> value.length() >= 4
                    ? "**** **** **** " + value.substring(value.length() - 4) : "****";
            case SOCIAL_ACCOUNT -> value.length() > 2 ? value.substring(0, 2) + "***" : "***";
        };
    }
}
```

### 12.4.4 规则引擎

```java
package com.jianli.privacy;

import org.springframework.stereotype.Component;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeParseException;
import java.util.*;
import java.util.function.Predicate;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Component
public class PrivacyDetector {

    public static final String RULE_VERSION = "v1";

    private static final Pattern PHONE =
            Pattern.compile("(?<!\\d)(?:\\+?86)?1[3-9]\\d{9}(?!\\d)");
    private static final Pattern ID_CARD =
            Pattern.compile("(?<!\\d)\\d{17}[\\dXx](?!\\d)");
    private static final Pattern EMAIL =
            Pattern.compile("[A-Za-z0-9._%+\\-]+@[A-Za-z0-9.\\-]+\\.[A-Za-z]{2,}");
    private static final Pattern BANK_CARD =
            Pattern.compile("(?<!\\d)\\d{16,19}(?!\\d)");
    private static final Pattern SOCIAL =
            Pattern.compile("(?:微信|wechat|vx|v信|QQ)\\s*[:：]?\\s*[A-Za-z0-9_\\-]{5,20}",
                    Pattern.CASE_INSENSITIVE);

    private static final String ADMIN_CHAIN =
            "(?:[\\u4e00-\\u9fa5]{2,8}(?:省|自治区|特别行政区|市|区|县|镇|乡|街道)){1,6}";
    private static final String DOOR =
            "[^，。；;、\\n]{0,40}?(?:路|街|巷|弄|道|小区|花园|公寓|大厦)\\s*\\d{1,5}\\s*"
                    + "(?:号|弄)[^，。；;\\n]{0,20}?(?:\\d{1,5}\\s*(?:栋|幢|单元|室|楼))?";
    private static final Pattern ADDRESS = Pattern.compile(ADMIN_CHAIN + DOOR);

    private static final int[] ID_WEIGHTS = {7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2};
    private static final char[] ID_CHECK = {'1','0','X','9','8','7','6','5','4','3','2'};

    private record Rule(SensitiveType type, Pattern pattern, Predicate<String> validator) {}

    private static final List<Rule> RULES = List.of(
            new Rule(SensitiveType.PHONE, PHONE, null),
            new Rule(SensitiveType.ID_CARD, ID_CARD, PrivacyDetector::validIdCard),
            new Rule(SensitiveType.EMAIL, EMAIL, null),
            new Rule(SensitiveType.ADDRESS, ADDRESS, null),
            new Rule(SensitiveType.BANK_CARD, BANK_CARD, PrivacyDetector::luhn),
            new Rule(SensitiveType.SOCIAL, SOCIAL, null)
    );

    /** 扫描并返回按位置排序、合并重叠后的命中项 */
    public List<PrivacyHit> scan(String raw) {
        if (raw == null || raw.isBlank()) return List.of();
        NormalizedText nt = NormalizedText.of(raw);
        List<PrivacyHit> hits = new ArrayList<>();

        for (Rule rule : RULES) {
            Matcher m = rule.pattern().matcher(nt.text());
            while (m.find()) {
                String value = m.group();
                if (rule.validator() != null && !rule.validator().test(value)) continue;

                int[] range = nt.toOriginalRange(m.start(), m.end());
                String origin = raw.substring(range[0], range[1]);
                hits.add(new PrivacyHit(rule.type(), range[0], range[1],
                        Masker.mask(rule.type(), origin), rule.type().advice()));
            }
        }
        return mergeOverlaps(hits);
    }

    public boolean passed(String raw) { return scan(raw).isEmpty(); }

    // ---------------- 校验 ----------------

    static boolean validIdCard(String id) {
        if (id == null || id.length() != 18) return false;
        int sum = 0;
        for (int i = 0; i < 17; i++) {
            char c = id.charAt(i);
            if (!Character.isDigit(c)) return false;
            sum += (c - '0') * ID_WEIGHTS[i];
        }
        if (ID_CHECK[sum % 11] != Character.toUpperCase(id.charAt(17))) return false;

        String birthday = id.substring(6, 14);
        try {
            LocalDate d = LocalDate.parse(birthday, DateTimeFormatter.BASIC_ISO_DATE);
            return d.getYear() >= 1900 && d.getYear() <= LocalDate.now().getYear();
        } catch (DateTimeParseException e) {
            return false;
        }
    }

    static boolean luhn(String digits) {
        if (digits == null || digits.length() < 16) return false;
        int sum = 0;
        boolean dbl = false;
        for (int i = digits.length() - 1; i >= 0; i--) {
            int d = digits.charAt(i) - '0';
            if (dbl) { d *= 2; if (d > 9) d -= 9; }
            sum += d;
            dbl = !dbl;
        }
        return sum % 10 == 0;
    }

    /** 重叠区间保留更长的那条（如身份证被银行卡规则重复命中） */
    private List<PrivacyHit> mergeOverlaps(List<PrivacyHit> hits) {
        List<PrivacyHit> sorted = hits.stream()
                .sorted(Comparator.comparingInt(PrivacyHit::start)
                        .thenComparing(h -> -(h.end() - h.start())))
                .toList();

        List<PrivacyHit> out = new ArrayList<>();
        for (PrivacyHit h : sorted) {
            if (!out.isEmpty()) {
                PrivacyHit last = out.get(out.size() - 1);
                if (h.start() < last.end()) {
                    if ((h.end() - h.start()) > (last.end() - last.start())) {
                        out.set(out.size() - 1, h);
                    }
                    continue;
                }
            }
            out.add(h);
        }
        return List.copyOf(out);
    }
}
```

## 12.5 审核落库（事务边界是重点）

```java
package com.jianli.privacy.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.jianli.privacy.PrivacyDetector;
import com.jianli.privacy.PrivacyHit;
import com.jianli.privacy.entity.PrivacyReview;
import com.jianli.privacy.repository.PrivacyReviewRepository;
import com.jianli.resume.service.ResumeTextNormalizer;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Propagation;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Slf4j
@Service
@RequiredArgsConstructor
public class PrivacyReviewService {

    private final PrivacyDetector detector;
    private final PrivacyReviewRepository repository;
    private final ObjectMapper objectMapper;
    private final ResumeTextNormalizer normalizer;

    /** 预检：不落库 */
    public List<PrivacyHit> precheck(String content) {
        return detector.scan(content);
    }

    /**
     * 检测 + 落库。
     * REQUIRES_NEW：发帖失败回滚时，审核记录必须留下来（审计）。
     */
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public ReviewOutcome checkAndRecord(Long userId, String scene, String content) {
        long start = System.currentTimeMillis();
        List<PrivacyHit> hits = detector.scan(content);

        PrivacyReview review = new PrivacyReview();
        review.setUserId(userId);
        review.setScene(scene);
        review.setStatus(hits.isEmpty() ? "PASSED" : "REJECTED");
        review.setHitCount(hits.size());
        review.setHitDetail(toJson(hits));          // 只存脱敏片段
        review.setRuleVersion(PrivacyDetector.RULE_VERSION);
        review.setAiChecked(false);
        review.setContentHash(normalizer.sha256(content));   // 不存原文
        review.setDurationMs((int) (System.currentTimeMillis() - start));

        return new ReviewOutcome(repository.save(review), hits);
    }

    private String toJson(List<PrivacyHit> hits) {
        try {
            return objectMapper.writeValueAsString(hits.stream().map(h -> java.util.Map.of(
                    "type", h.type().name(),
                    "start", h.start(),
                    "end", h.end(),
                    "maskedSnippet", h.maskedSnippet()
            )).toList());
        } catch (Exception e) {
            return "[]";
        }
    }

    public record ReviewOutcome(PrivacyReview review, List<PrivacyHit> hits) {}
}
```

```java
@Service
@RequiredArgsConstructor
public class PostService {

    private final PostRepository postRepository;
    private final AnalysisReportRepository reportRepository;
    private final PrivacyReviewService privacyReviewService;
    private final JdRepository jdRepository;
    private final ObjectMapper objectMapper;

    @Transactional
    public PostVO publish(Long userId, PublishPostRequest req) {
        // ① 报告归属与状态
        AnalysisReport report = reportRepository.findByIdAndUserId(req.reportId(), userId)
                .orElseThrow(() -> new BizException(ErrorCode.REPORT_NOT_OWNED));
        if (!List.of("SUCCESS", "PARTIAL").contains(report.getStatus())) {
            throw new BizException(ErrorCode.ANALYSIS_NOT_READY);
        }
        if (postRepository.existsByReportId(report.getId())) {
            throw new BizException(ErrorCode.POST_DUPLICATED);
        }

        // ② 审核（独立事务，拒绝也会留痕）
        String toCheck = String.join("\n", req.title(),
                req.content() == null ? "" : req.content(), req.resumeContent());
        var outcome = privacyReviewService.checkAndRecord(userId, "POST_PUBLISH", toCheck);

        if ("REJECTED".equals(outcome.review().getStatus())) {
            throw new BizException(ErrorCode.POST_PRIVACY_REJECTED,
                    Map.of("reviewId", outcome.review().getId(),
                            "hits", outcome.hits()));
        }

        // ③ 快照 + 落库
        Post post = new Post();
        post.setUserId(userId);
        post.setReportId(report.getId());
        post.setPrivacyReviewId(outcome.review().getId());
        post.setTitle(req.title());
        post.setContent(req.content());
        post.setResumeContent(req.resumeContent());
        post.setReportSnapshot(buildSnapshot(report));      // 报告 JSON 快照
        post.setOverallScore(report.getOverallScore());
        post.setIsAnonymous(Boolean.TRUE.equals(req.isAnonymous()));
        post.setStatus("PUBLISHED");
        post.setViewCount(0);
        post.setCommentCount(0);
        post.setUpCount(0);
        post.setDownCount(0);
        post.setHotScore(0.0);

        // 冗余维度：便于筛选
        jdRepository.findById(report.getJdId()).ifPresent(jd -> {
            post.setTargetPosition(jd.getTitle());
            post.setYearsOfExperience(jd.getParsedJson() == null ? 0 : minYearsOf(report));
        });

        return PostVO.of(postRepository.save(post), userId);
    }
}
```

> **`throw new BizException(43002, data)` 之后**，`publish` 的事务整体回滚（post 不会插入），但 `checkAndRecord` 因为 `REQUIRES_NEW` 已经单独提交，所以 REJECTED 记录留下来了。**这就是"业务失败但审计成功"的实现方式。**

```js
const textareaRef = ref()

async function submit() {
  // ① 预检（体验优化）
  const pre = await privacyApi.precheck({
    title: form.title, content: form.content, resumeContent: form.resumeContent
  })
  if (!pre.passed) {
    hits.value = pre.hits
    hitDialog.value = true
    return
  }

  // ② 正式发布（服务端会再审一次，以服务端为准）
  try {
    const post = await postApi.publish({ ...form })
    ElMessage.success('发布成功')
    router.push(`/community/${post.id}`)
  } catch (e) {
    if (e.code === 43002) {
      hits.value = e.data.hits
      hitDialog.value = true          // 拦截器不弹通用提示，这里接管
    } else {
      throw e
    }
  }
}

function locate(hit) {
  const ta = textareaRef.value?.textarea
  if (!ta) return
  ta.focus()
  ta.setSelectionRange(hit.start, hit.end)   // 直接选中
  // 滚动到可见
  const style = window.getComputedStyle(ta)
  const lineHeight = parseFloat(style.lineHeight) || 20
  const lines = form.resumeContent.slice(0, hit.start).split('\n').length
  ta.scrollTop = Math.max(0, lines * lineHeight - ta.clientHeight / 2)
}
```

```java
class PrivacyDetectorTest {

    private final PrivacyDetector detector = new PrivacyDetector();

        }
    }

    }
```

## 12.11 报错怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| `138-0013-8000` 检测不到 | 归一化没吞分隔符 | 检查 `NormalizedText.of` 的数字间隔判断 |
| 命中位置高亮错位 | `indexMap` 映射错 / 未设末位 | 补 `map[sb.length()] = src.length()` |
| 18 位订单号被误判身份证 | 没做校验位 | 确认 `validIdCard` 被调用 |
| "杭州市" 被误判住址 | 规则只要行政区划 | 加门牌结构要求（本项目已加） |
| 发帖失败后审核记录也丢了 | 用了同一个事务 | 必须是 `REQUIRES_NEW` |
| 前端拿不到 `hits` | 拦截器把 43002 当普通错误弹了提示 | 拦截器里对 43002 只 reject 不 toast |
| 预检很慢 | 文本超长 | 限制审核文本 ≤ 50KB，超长截断 |

## 12.12 自测题

1. **为什么规则优于 AI 做审核？**（确定性、延迟、可审计、隐私自洽、可测试、不受额度影响）
2. **为什么要归一化再匹配，还要维护下标映射？** → 否则 `138-0013-8000` 漏检；映射回原文才能高亮。
3. **身份证/银行卡为什么要二次校验？** → 纯正则在 18 位数字上误报率极高。
4. **为什么拒绝也要落库，而且要用 REQUIRES_NEW？** → 审计与规则调优；外层回滚时记录要保留。
5. **为什么审核表不存原文？** → 否则数据库里永久多一份敏感信息副本。
6. **预检为什么返回 200，发帖为什么 422？** → 查询成功 vs 创建被拒，语义不同。
7. **前端校验了为什么后端还要查？** → 前端只是体验，安全边界必须在服务端。
